### ✅ Права доступа (canEdit)
**Статус:** ✅ **КОРРЕКТНО**

```typescript
const canEdit = computed(() => {
  const role = auth.role as Me['role'] | undefined
  return role === 'admin' || role === 'manager' || role === 'warehouse'
})
```

- Правильные роли: `admin`, `manager`, `warehouse`
- Используется в `listConfig.showCreate` и `listConfig.canCreate`
- Используется в `v-if="canEdit"` для кнопок массового добавления
