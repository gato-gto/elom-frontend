## ✅ РЕШЕНИЕ

### Изменения в `MobileNavigation.vue`:

1. **Добавлен динамический список справочников:**
   ```typescript
   // Build navigation from router configuration (синхронизация с desktop)
   const navigationItems = computed((): NavigationItem[] => {
     // ... логика извлечения из роутера
   })
   
   // Reference Data - справочники (синхронизация с desktop)
   const referenceData = computed(() => {
     return navigationItems.value.filter(item => 
       ['reference_data'].includes(item.category || '')
     )
   })
   ```

2. **Обновлен шаблон:**
   ```vue
   <!-- Reference Data submenu -->
   <div v-if="showReferenceDataMenu" class="mobile-reports-submenu">
     <router-link 
       v-for="item in referenceData" 
       :key="item.name"
       :to="item.path" 
       class="mobile-submenu-item" 
       @click="closeMoreMenu"
     >
       {{ item.title }}
     </router-link>
   </div>
   ```

3. **Исправлена устаревшая проверка роли:**
   - Убрана проверка `role === 'director'` (устаревшая роль)
   - Оставлена только `role === 'admin'`
