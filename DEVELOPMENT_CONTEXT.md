# ELOM Frontend - Контекст разработки

## 🏗️ Архитектура проекта

### Технологический стек
- **Vue 3** + Composition API
- **TypeScript** для типизации
- **Pinia** для управления состоянием
- **Vite** для сборки
- **Tailwind CSS** + **DaisyUI** для стилизации
- **Axios** для HTTP запросов
- **Vue Router** для маршрутизации

### Структура проекта
```
src/
├── api/                    # API клиент и типы
│   ├── client.ts          # HTTP клиент с авторизацией
│   ├── endpoints.ts       # Endpoints API
│   └── types.ts           # TypeScript типы
├── components/            # Переиспользуемые компоненты
│   ├── FormField.vue      # Универсальное поле формы
│   ├── FilterPanel.vue    # Панель фильтров
│   ├── ListHeader.vue     # Заголовок списка
│   ├── ModernPagination.vue # Современная пагинация
│   └── ...
├── pages/                 # Страницы приложения
│   ├── Materials/         # Материалы
│   ├── Objects/           # Объекты
│   ├── Purchases/         # Закупки
│   ├── Stocks/            # Остатки
│   ├── WriteOffs/         # Списания
│   ├── Employees/         # Сотрудники
│   ├── Units/             # Единицы измерения
│   └── Reports/           # Отчеты
├── stores/                # Pinia stores
│   ├── auth.ts           # Авторизация
│   ├── materials.ts      # Материалы
│   ├── objects.ts        # Объекты
│   ├── purchases.ts      # Закупки
│   ├── stockSnapshots.ts # Движения остатков
│   ├── writeOffs.ts      # Списания
│   └── ...
├── composables/           # Композиционные функции
│   ├── usePagination.ts  # Логика пагинации
│   ├── useLoading.ts     # Состояния загрузки
│   └── useAnimations.ts  # Анимации
├── utils/                 # Утилиты
│   ├── formatters.ts     # Форматирование данных
│   ├── debounce.ts       # Debounce функции
│   └── unitRounding.ts   # Округление единиц
└── styles/               # Стили
    └── animations.css    # Анимации
```
