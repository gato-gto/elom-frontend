### Изменение #1: Исправление `no-undef` в `.cjs` скриптах ✅
**Файлы:**

- `scripts/fix-reports-pagination.cjs`
- `scripts/remove-duplicate-styles.cjs`

**Проблема:** ESLint не распознавал `console`, `require`, `module` и другие Node.js глобальные переменные в CommonJS модулях.

**Решение:**

2. Добавил отдельное правило в `eslint.config.js` для `.cjs` файлов с правильными глобальными переменными и `sourceType: 'commonjs'`

**Результат:** Исправлено 21 ошибка

### Изменение #4: Исправление типов в SupplierSearchSelect.vue ✅
**Файл:** `src/components/SupplierSearchSelect.vue`

**Проблема:** ESLint не распознавал глобальные типы `HTMLDivElement`, `MouseEvent`, `Node` в Vue SFC.

**Решение:** 
1. Заменил `NodeJS.Timeout` на `ReturnType<typeof setTimeout>`
2. Добавил `/* eslint-disable no-undef */` в начало `<script setup>`
3. Использовал `InstanceType<typeof HTMLDivElement>` для ref-типов

**Результат:** Исправлено 5 ошибок

**Статус:** ✅ Завершено

### Изменение #5: Обновление ESLint конфигурации ✅
**Файл:** `eslint.config.js`

**Проблема:** Flat config ESLint не применял правила к `.cjs` файлам.

**Решение:** Добавил отдельную секцию конфигурации:
```javascript
{
  files: ['**/*.cjs', 'scripts/**/*.js'],
  languageOptions: {
    globals: {
      console: 'readonly',
      require: 'readonly',
      process: 'readonly',
      __dirname: 'readonly',
      __filename: 'readonly',
      module: 'readonly',
      exports: 'readonly'
    },
    sourceType: 'commonjs'
  },
  rules: {
    'no-console': 'off'
  }
}
```

**Результат:** Все `.cjs` файлы теперь корректно проверяются

**Статус:** ✅ Завершено
