## 🚀 ШАГ 4: ПЕРВЫЕ ДЕЙСТВИЯ

### Если вы Бригадир (Brigadier):

#### ✅ Проверьте остатки на объекте:
```
Остатки → По объектам → найти свой объект
→ Видите: что и сколько материалов
```

#### ✅ Создайте тестовую закупку:
```
Закупки → Добавить закупку
→ Объект: ваш объект
→ Поставщик: любой
→ Добавить позицию: любой материал
→ Количество: 1
→ Сохранить
→ Проверить: Остатки увеличились
→ Удалить тестовую закупку
```

#### ✅ Создайте тестовое списание:
```
Списания → Добавить списание
→ Объект: ваш (материалы загрузятся автоматически)
→ Материал: выбрать
→ Количество: 0.5
→ Этап: подставится из карточки объекта
→ Сохранить
→ Проверить: Остаток уменьшился
→ Удалить тестовое списание
```

✅ **Поздравляем! Теперь вы готовы к реальной работе.**

---

#### ✅ Посмотрите общую картину:

Отчёты → По объектам

#### ✅ Проверьте работу бригадиров:

## 🆘 SOS — СРОЧНАЯ ПОМОЩЬ

### 🔴 Проблема: Не могу войти

**Решение**:
1. Проверьте логин/пароль (регистр важен!)
2. Попробуйте другой браузер
3. Очистите кэш (Ctrl+Shift+Del)
4. Обратитесь к администратору

---

### 🔴 Проблема: Список пустой

**Решение**:
1. Кнопка "Сбросить фильтры"
2. Проверить: не слишком ли строгие фильтры
3. F5 — обновить страницу

---

### 🔴 Проблема: Ошибка при сохранении

**Решение**:
1. Прочитайте текст ошибки (подсказывает что не так)
2. Проверьте все поля со звёздочкой (*) заполнены
3. Проверьте: количество > 0, даты правильные
4. Скриншот ошибки → отправьте в поддержку

---

### 🔴 Проблема: Не вижу нужный материал в списании

**Решение**:
1. Проверьте: выбран ли объект
2. Материалы загружаются только после выбора объекта
3. Если материала нет — значит его не закупали для этого объекта
4. Сначала создайте закупку этого материала

---

### 🔴 Проблема: Отрицательный остаток (−150 кг)

**Что это**: Списали больше чем закупили

**Решение**:
1. Остатки → Движения → фильтр объект+материал
2. Проверить все приходы и расходы
3. Найти ошибку:
   - Забыли зарегистрировать закупку?
   - Ошибка в количестве при списании?
4. Исправить: создать закупку или удалить ошибочное списание

## 💡 5 ЛАЙФХАКОВ

### 1️⃣ Быстрый поиск материала
```
Закупки → начните вводить название материала в позиции
→ Автодополнение покажет варианты
→ Выбрать Enter
```

### 2️⃣ Создание поставщика на лету
```
Закупки → поле "Поставщик"
→ Вводите название нового
→ "+ Создать поставщика"
→ Минимум данных → готово
```

### 3️⃣ Автозаполнение в списании
```
Списания → выбрать объект
→ Ответственный подставится сам
→ Выбрать материал
→ Единица подставится сама
→ Остаток покажется
```

### 4️⃣ Фильтрация + экспорт
```
Любой список → настроить фильтры
→ Видите только нужное
→ Экспорт → скачивается только отфильтрованное
```

### 5️⃣ Сортировка вложенных таблиц
```
Остатки → По объектам
→ В таблице материалов клик на "Остаток"
→ Сортировка от большего к меньшему
→ Видите что заканчивается
```
