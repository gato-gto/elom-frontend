## 1. ФОРМА МАТЕРИАЛОВ

**Путь**: Материалы → Добавить материал

### Зачем нужна:
Создание справочника всех материалов, которые используются на стройке. Один раз добавили материал — потом используете его во всех закупках.

### Поля формы:

#### 📌 Название **(обязательно)**
- **Что вводить**: Полное название материала
- **Примеры**: 
  - "Цемент М400 50кг"
  - "Кабель ВВГ 3×2.5"
  - "Профиль гипсокартонный CD-60"
- **Зачем**: Основное имя для поиска и отображения

#### 📌 Артикул (SKU)
- **Что вводить**: Уникальный код материала
- **Примеры**: 
  - "CEM-400-50"
  - "CABLE-VVG-3x2.5"
  - "PROF-CD-60"
- **Зачем**: Быстрый поиск, учёт, интеграция с другими системами
- **Важно**: Должен быть уникальным в системе

#### 📌 Категория
- **Что выбирать**: Группу материалов
- **Примеры**: 
  - "Строительные материалы"
  - "Электрика"
  - "Сантехника"
  - "Отделочные материалы"
- **Зачем**: Группировка и фильтрация в отчётах

#### 📌 Единица измерения **(обязательно)**
- **Что выбирать**: В чём меряете материал
- **Варианты**: кг, м, м², м³, шт, л, упак, рулон
- **Зачем**: 
  - Автоматически подставляется в закупках
  - Автоматически подставляется в списаниях
  - Правильный учёт остатков
- **Важно**: Выбирайте ту единицу, в которой **чаще всего** работаете с этим материалом

#### 📌 Описание
- **Что вводить**: Подробная информация
- **Примеры**:
  - "Портландцемент марки М400, мешки по 50кг"
  - "Медный кабель силовой, сечение 3×2.5мм²"
- **Зачем**: Дополнительная информация для идентификации

#### 📌 Производитель
- **Что вводить**: Название производителя/бренда
- **Примеры**: "Узбекцемент", "Knauf", "Bosch"
- **Зачем**: Контроль качества, поиск по бренду

#### 📌 Фото
- **Что загружать**: Изображение материала
- **Форматы**: JPG, PNG, WEBP
- **Размер**: до 10 МБ
- **Зачем**: Визуальная идентификация, особенно полезно для похожих материалов

#### 📌 Активен
- **Галочка**: Материал используется
- **Без галочки**: Материал устарел, больше не закупается
- **Зачем**: В списках и фильтрах по умолчанию показываются только активные

### Что происходит после сохранения:
- ✅ Материал появляется в справочнике
- ✅ Его можно выбирать в закупках
- ✅ Его можно выбирать в списаниях
- ✅ По нему можно формировать отчёты

## 2. ФОРМА ОБЪЕКТОВ

**Путь**: Объекты → Добавить объект

### Зачем нужна:
Регистрация строительных объектов (домов, зданий). Без объекта нельзя создать закупку или списание.

### Поля формы:

#### 📌 Название **(обязательно)**
- **Что вводить**: Название объекта
- **Примеры**:
  - "ЖК Солнечный, дом №1"
  - "Торговый центр Mega"
  - "Завод №3, цех 5"
- **Зачем**: Основная идентификация объекта

#### 📌 Адрес
- **Что вводить**: Полный адрес
- **Пример**: "г. Ташкент, ул. Нукусская, 1А"
- **Зачем**: Локация объекта, поиск на карте

#### 📌 Ответственный **(обязательно)**
- **Что выбирать**: Бригадира
- **Важно**: Только пользователи с ролью **Brigadier**!
- **Зачем**: 
  - Он будет отвечать за объект
  - Его данные автоматически подставятся в закупках
  - Его данные автоматически подставятся в списаниях

#### 📌 Ключевое лицо
- **Что вводить**: ФИО контактного лица на объекте
- **Пример**: "Иванов Иван Петрович"
- **Зачем**: Контакт для связи по вопросам объекта

#### 📌 Телефон ключевого лица
- **Что вводить**: Телефон для связи
- **Пример**: "+998 90 123 45 67"
- **Зачем**: Быстрая связь с объектом

#### 📌 Дата начала работ
- **Что вводить**: Когда начались работы
- **По умолчанию**: Сегодня
- **Зачем**: Хронология проекта, отчётность

#### 📌 Дата окончания работ
- **Что вводить**: Планируемая дата завершения
- **Необязательно**: Можно не указывать
- **Зачем**: Планирование, контроль сроков

#### 📌 Геолокация (координаты)
- **Что вводить**: Широта и долгота или ссылка на карту
- **Пример**: 
  - Широта: 41.311081
  - Долгота: 69.240562
  - Или ссылка: https://maps.google.com/?q=41.311081,69.240562
- **Зачем**: 
  - Показ на карте
  - Уведомления в Telegram с кнопкой "Открыть на карте"

#### 📌 Активен
- **Галочка**: Объект в работе
- **Без галочки**: Объект завершён или заморожен
- **Зачем**: Активные объекты показываются первыми в списках

### Что происходит после сохранения:
- ✅ Объект появляется в списке объектов
- ✅ На него можно создавать закупки
- ✅ На него можно создавать списания
- ✅ По нему можно смотреть остатки
- ✅ Отправляется Telegram-уведомление (если настроено)

## 3. ФОРМА ЗАКУПОК

**Путь**: Закупки → Добавить закупку

### Зачем нужна:
Регистрация всех поступлений материалов на объект. Каждая закупка автоматически увеличивает остатки материалов.

### Секция 1: Основная информация

#### 📌 Дата **(обязательно)**
- **Что вводить**: Дата закупки/поставки
- **По умолчанию**: Сегодня
- **Зачем**: 
  - Хронология
  - Фильтрация по периодам
  - Расчёт остатков на дату

#### 📌 Объект **(обязательно)**
- **Что выбирать**: На какой объект закупка
- **Зачем**: 
  - Привязка материалов к объекту
  - Расчёт остатков по объекту
  - Отчётность

#### 📌 Поставщик **(обязательно)**
- **Что делать**: Выберите из списка или создайте нового
- **Как создать нового**:
  1. Начните вводить название
  2. Появится "**+ Создать поставщика**"
  3. Введите минимальные данные
  4. Сохранится автоматически
- **Зачем**: 
  - Учёт поставщиков
  - Анализ цен
  - Контроль качества

#### 📌 Номер счёта/накладной
- **Что вводить**: Номер документа от поставщика
- **Пример**: "INV-2025-001", "Н-12345"
- **Зачем**: Связь с бухгалтерией, поиск документов

#### 📌 Валюта
- **Что выбирать**: В какой валюте цены
- **По умолчанию**: UZS (узбекский сум)
- **Зачем**: Правильный расчёт сумм, отчётность

#### 📌 Ответственный **(обязательно)**
- **Что выбирать**: Кто отвечает за закупку
- **Важно**: Только **Brigadier** (бригадир)!
- **Зачем**: 
  - Персональная ответственность
  - Уникальная нумерация закупок
  - Отчётность по ответственным

#### 📌 Комментарий
- **Что вводить**: Любые примечания
- **Примеры**:
  - "Срочная доставка для фундамента"
  - "Со скидкой 10%"
  - "Частичная оплата"
- **Зачем**: Дополнительная информация для коллег

### Секция 2: Материалы в закупке

Здесь добавляете каждый материал, который купили.

#### Для каждого материала указываете:

**📌 Материал** *(обязательно)*
- **Что выбирать**: Материал из справочника
- **Поиск**: Начните вводить название — появится автодополнение
- **Зачем**: Связь с остатками, правильный учёт

**📌 Единица измерения**
- **Автоматически**: Подставляется из материала
- **Можно изменить**: Если купили в другой единице
- **Пример**: Материал учитывается в кг, но купили тонну (т)
- **Зачем**: Система автоматически сконвертирует при расчёте остатков

**📌 Количество** *(обязательно)*
- **Что вводить**: Сколько купили
- **Пример**: 2000 (если 2000 кг), 5.5 (если 5.5 метров)
- **Зачем**: 
  - Расчёт суммы
  - Приход на остатки
  - Отчётность

**📌 Цена за единицу**
- **Что вводить**: Сколько стоит одна единица
- **Пример**: 2500 (если 1 кг стоит 2500 сум)
- **Необязательно**: Можно не указывать
- **Зачем**: 
  - Автоматический расчёт суммы (количество × цена)
  - Анализ цен в отчётах

**📌 Сумма**
- **Автоматически**: Рассчитывается как количество × цена
- **Пример**: 2000 кг × 2500 = 5,000,000 сум
- **Зачем**: Итоговая стоимость позиции

#### Как добавить несколько материалов:
1. Нажмите **"+ Добавить позицию"**
2. Заполните материал, количество, цену
3. Повторите для каждого материала
4. Итоговая сумма закупки покажется внизу автоматически

### Секция 3: Фотографии

#### 📌 Фотоинструкции (необязательно)
- **Что загружать**: Фото накладных, чеков, упаковки до работ
- **Когда**: При создании или до начала использования
- **Форматы**: JPG, PNG
- **Зачем**: 
  - Подтверждение покупки
  - Проверка качества
  - Контроль бухгалтерии

#### 📌 Фотоотчёт **(обязательно при статусе "Выполнено")**
- **Что загружать**: Фото после получения материалов
- **Когда**: При смене статуса на "Выполнено"
- **Зачем**: 
  - Подтверждение получения
  - Визуальный контроль
  - Отправляется в Telegram

### Статусы закупки:

#### 🆕 Новая (по умолчанию)
- Закупка только создана
- Можно редактировать всё
- Фотоотчёт необязателен

#### ✅ Выполнено
- Материалы получены и размещены на объекте
- **Обязательно**: загрузите фотоотчёт!
- Закупка становится неизменяемой
- Отправляется Telegram-уведомление

#### ❌ Отменена
- Закупка не состоялась
- Закупка становится неизменяемой
- Остатки не изменяются

### Что происходит после сохранения:
1. ✅ Генерируется уникальный номер (например, "PUR-2025-0042")
2. ✅ Рассчитывается общая сумма всех позиций
3. ✅ Создаются записи в журнале движений (+приход материалов)
4. ✅ Увеличиваются остатки материалов на объекте
5. ✅ Отправляется Telegram-уведомление с деталями
6. ✅ Логируется в системе аудита

### Пример заполнения:

```
Дата: 10.11.2025
Объект: ЖК Солнечный, дом №1
Поставщик: ООО "СтройМатериалы"
Номер счёта: INV-2025-1042
Валюта: UZS
Ответственный: Иванов И.П. (бригадир)
Комментарий: Материалы для фундамента

Позиции:
1. Цемент М400 — 2000 кг × 2500 = 5,000,000
2. Песок речной — 10 м³ × 150,000 = 1,500,000
3. Арматура 12мм — 500 м × 8,000 = 4,000,000

Итого: 10,500,000 UZS

Фото: [накладная.jpg, материалы_на_складе.jpg]
```

## 4. ФОРМА СПИСАНИЙ

**Путь**: Списания → Добавить списание

### Зачем нужна:
Учёт расхода (использования) материалов на объекте. Каждое списание автоматически уменьшает остатки.

### Особенность формы:
🎯 **Умное автозаполнение** — система подсказывает данные и фильтрует списки

### Поля формы:

#### 📌 Дата **(обязательно)**
- **Что вводить**: Когда израсходовали материал
- **По умолчанию**: Сегодня
- **Зачем**: Хронология расхода, расчёт остатков на дату

#### 📌 Объект **(обязательно)**
- **Что выбирать**: С какого объекта списываете
- **Что происходит при выборе**:
  - 🎯 Материалы фильтруются — показываются только те, что есть на этом объекте
  - 🎯 Ответственный подставляется автоматически из объекта
- **Зачем**: Привязка к объекту, правильный расчёт остатков

#### 📌 Материал **(обязательно)**
- **Что выбирать**: Какой материал списываете
- **Важно**: В списке только материалы, закупленные для выбранного объекта!
- **Что происходит при выборе**:
  - 🎯 Единица измерения подставляется автоматически
  - 🎯 Загружается текущий остаток материала
  - 🎯 Показывается информационный блок с остатком
- **Зачем**: Учёт расхода конкретного материала

#### 📌 Единица измерения
- **Автоматически**: Подставляется из справочника материала
- **Заблокирована**: Если у материала задана базовая единица
- **Зачем**: Правильный учёт, конверсия единиц

#### 📌 Количество **(обязательно)**
- **Что вводить**: Сколько материала израсходовали
- **Пример**: 500 (если 500 кг), 25.5 (если 25.5 метров)
- **Проверка**: Система покажет текущий остаток, но **не запретит** списание
- **Зачем**: 
  - Расход на остатках (со знаком минус)
  - Отчётность по использованию

#### 📌 Этап работ **(обязательно)**
- **Что выбирать**: На каком этапе используется материал
- **Варианты**:
  - **Приемка** — приёмка объекта в работу
  - **Заявка** — планирование потребности
  - **Доставка** — фактическое поступление
  - **После черновых** — расход при черновых работах (чаще всего)
  - **Сдача** — расход при сдаче объекта
- **Зачем**: 
  - Аналитика по этапам
  - Контроль выполнения
  - Отчётность для заказчика

#### 📌 Ответственный **(обязательно)**
- **Автоматически**: Подставляется ответственный за объект
- **Можно изменить**: Выберите другого пользователя
- **Зачем**: Персональная ответственность за расход

#### 📌 Комментарий
- **Что вводить**: Подробности списания
- **Примеры**:
  - "Заливка фундамента, секция А"
  - "Ремонт после протечки"
  - "Финальная отделка"
- **Зачем**: Детализация для отчётов и проверок

### Информационный блок «Актуальный остаток»:

При выборе объекта и материала система покажет:

```
ℹ️ Актуальный остаток материала
   1,500.250000 кг
```

- **Что это**: Сколько материала сейчас на объекте
- **Зачем**: Справочная информация перед списанием
- **Важно**: Система **НЕ блокирует** списание, даже если остаток меньше

### Что происходит после сохранения:
1. ✅ Создаётся запись в журнале движений (−расход материала)
2. ✅ Уменьшается остаток материала на объекте
3. ✅ Логируется в системе аудита
4. ✅ Можно увидеть в отчётах

### Пример заполнения:

```
Дата: 10.11.2025
Объект: ЖК Солнечный, дом №1
  → Автоматически загрузились материалы для этого объекта
  → Ответственный: Иванов И.П. (подставился автоматически)

Материал: Цемент М400
  → Единица измерения: кг (подставилась автоматически)
  → Показывается: Актуальный остаток: 2,000.000000 кг

Количество: 500
Этап работ: После черновых
Ответственный: Иванов И.П.
Комментарий: Заливка фундамента блок А

→ Сохранить

Результат:
- Остаток: 2000 - 500 = 1500 кг
- В журнале: запись "−500 кг"
```

## 5. ФОРМА ПОСТАВЩИКОВ

**Путь**: Поставщики → Добавить поставщика

### Зачем нужна:
База поставщиков для быстрого выбора при создании закупок.

### Поля формы:

#### 📌 Название **(обязательно)**
- **Что вводить**: Полное название компании
- **Примеры**: 
  - "ООО СтройМатериалы"
  - "ИП Иванов"
  - "ТОО Торговый Дом"
- **Зачем**: Идентификация поставщика

#### 📌 Контактное лицо
- **Что вводить**: ФИО менеджера
- **Пример**: "Петров Петр Сергеевич"
- **Зачем**: С кем связываться по заказам

#### 📌 Телефон
- **Что вводить**: Номер для связи
- **Пример**: "+998 71 123 45 67"
- **Зачем**: Быстрая связь для заказов

#### 📌 Email
- **Что вводить**: Электронная почта
- **Пример**: "info@stroymat.uz"
- **Зачем**: Официальная переписка, заявки

#### 📌 Адрес
- **Что вводить**: Адрес офиса/склада
- **Пример**: "г. Ташкент, ул. Промышленная, 15"
- **Зачем**: Навигация к складу, юридический адрес

#### 📌 Активен
- **Галочка**: С поставщиком работаем
- **Без галочки**: Больше не сотрудничаем
- **Зачем**: Активные показываются первыми при выборе

## 6. ФОРМА СОТРУДНИКОВ

**Путь**: Сотрудники → Добавить сотрудника
**Доступ**: Только Admin и Director

### Зачем нужна:
Регистрация пользователей системы с назначением ролей и объектов.

### Поля формы:

#### 📌 Имя пользователя (username) **(обязательно)**
- **Что вводить**: Уникальный логин
- **Примеры**: "ivanov", "petrov.petr", "aziz_builder"
- **Важно**: Только латиница, цифры, точки, подчёркивания
- **Зачем**: Вход в систему

#### 📌 Имя / Фамилия
- **Что вводить**: Реальные имя и фамилия
- **Пример**: Имя: "Иван", Фамилия: "Иванов"
- **Зачем**: Отображение в интерфейсе, отчётах, уведомлениях

#### 📌 Email
- **Что вводить**: Электронная почта
- **Пример**: "ivanov@company.uz"
- **Зачем**: Уведомления, восстановление пароля (в планах)

#### 📌 Роль **(обязательно)**
- **Что выбирать**: Должность в системе
- **Варианты**:
  - **Admin** — для IT-администратора
  - **Director** — для руководства
  - **Coordinator** — для координаторов проектов
  - **Brigadier** — для бригадиров (могут создавать закупки и быть ответственными за объекты)
  - **Buyer** — для закупщиков
  - **Site Manager** — для менеджеров объектов
- **Зачем**: Определяет доступ к функциям

#### 📌 Телефон
- **Что вводить**: Номер телефона
- **Обязательно**: Для всех ролей кроме Admin и Director
- **Пример**: "+998 90 123 45 67"
- **Зачем**: Связь, уведомления

#### 📌 Назначенные объекты
- **Что выбирать**: На каких объектах работает сотрудник
- **Множественный выбор**: Можно выбрать несколько
- **Для кого**: Brigadier, Buyer, Site Manager, Coordinator
- **Зачем**: 
  - Ограничение доступа (видят только свои объекты)
  - Автоподстановка в формах

#### 📌 Пароль **(при создании)**
- **Что вводить**: Начальный пароль для входа
- **Требования**: минимум 8 символов
- **Зачем**: Первый вход в систему
- **Смена**: После первого входа пользователь может сменить

#### 📌 Активен
- **Галочка**: Пользователь работает
- **Без галочки**: Уволен/заблокирован
- **Зачем**: Неактивные не могут войти в систему

### Пример создания бригадира:

```
Имя пользователя: ivanov_ivan
Имя: Иван
Фамилия: Иванов
Email: ivanov@company.uz
Роль: Brigadier (Бригадир)
Телефон: +998 90 123 45 67
Назначенные объекты: 
  ☑ ЖК Солнечный, дом №1
  ☑ ЖК Солнечный, дом №2
Пароль: IvanovPass2025!
Активен: ☑

→ Сохранить

Результат:
- Иванов может войти в систему
- Видит только дома №1 и №2
- Может создавать закупки на эти объекты
- Может быть ответственным за объекты
```

1. **Вместо таблиц — карточки** — удобнее для касаний
2. **Меню** — иконка ≡ слева вверху
3. **Все функции доступны** — просто другой вид
4. **Свайп** — некоторые действия через свайп

## ❓ ЧАСТЫЕ ВОПРОСЫ ПО ФОРМАМ

### В. Поле заблокировано (серое), не могу изменить
**О.** Скорее всего это:
- Единица измерения (подставляется из материала)
- Сумма в закупке (считается автоматически)
- Номер закупки (генерируется системой)
- Данные в архивированной записи

### В. При выборе материала ничего не происходит
**О.** Обновите страницу (F5). Если проблема повторяется — обратитесь в поддержку.

### В. Не сохраняется форма — показывает ошибки
**О.** Проверьте:
1. Все поля со звёздочкой (*) заполнены
2. Формат данных правильный (дата, число)
3. В закупке добавлена хотя бы 1 позиция
4. Ответственный — бригадир (в закупках и объектах)

### В. Ошибка "Это поле обязательно"
**О.** Заполните поле, отмеченное красным. Система подсказывает, какое именно поле пустое.

### В. В списке материалов при списании пусто
**О.** Сначала выберите объект — тогда загрузятся материалы для этого объекта.

## 🆘 РЕШЕНИЕ ПРОБЛЕМ

### Проблема: "Не могу найти нужный материал в списании"

**Решение**:
1. Проверьте, выбран ли объект — материалы загружаются только после выбора
2. Проверьте, закупался ли этот материал для данного объекта
3. Если не закупался — сначала создайте закупку

### Проблема: "Ошибка при сохранении закупки"

**Решение**:
1. Проверьте все обязательные поля (*)
2. Проверьте: добавлена ли хотя бы 1 позиция материала
3. Проверьте: ответственный — бригадир
4. Проверьте: количество > 0, цена ≥ 0
5. Скриншот ошибки → отправьте в поддержку

### Проблема: "Не могу изменить старую закупку"

**Решение**:
- Проверьте, не архивирована ли закупка (столбец "Архив")
- Если архив — обратитесь к Director/Admin для открытия периода

### Проблема: "Остатки отрицательные — это ошибка?"

**Решение**:
Отрицательный остаток означает **перерасход**:
- Списали больше, чем закупили
- Возможные причины:
  1. Забыли зарегистрировать закупку
  2. Списали лишнее по ошибке
  3. Материал использовался с другого объекта

**Действия**:
1. Проверьте журнал движений — все ли закупки учтены
2. Проверьте списания — нет ли ошибочных
3. Создайте корректирующую закупку (если материал действительно был)
