| 6 | **Остаток** | Текущий остаток | ✅ |

### Фильтры:
- 🔍 **Поиск** — по материалу, объекту

- 📦 **Материал** — списания материала

- 🟢 **> 0** — остаток есть (зелёный)
- 🟡 **= 0** — остаток закончился (жёлтый)
- 🔴 **< 0** — перерасход (красный, требует внимания!)

### Действия:

## 5. 📊 ОСТАТКИ → ДВИЖЕНИЯ

**Навигация**: Остатки → Движения

### Колонки таблицы:

| # | Колонка | Что показывает | Сортировка |
|---|---------|----------------|------------|
| 1 | **Дата** | Когда операция | ✅ |
| 2 | **Объект** | На каком объекте | ✅ |
| 3 | **Материал** | Какой материал | ✅ |
| 4 | **Количество** | ±количество + единица | ✅ |
| 5 | **Этап** | На каком этапе | ✅ |
| 6 | **Источник** | Откуда запись | — |
| 7 | **Ответственный** | Кто создал | ✅ |
| 8 | **Действия** | Просмотр источника | — |

### Типы записей:

#### ➕ Приход (зелёный)
- **Количество**: +2000 кг
- **Источник**: "Закупка #PUR-2025-0042"
- **Что означает**: Материал поступил на объект

#### ➖ Расход (красный)
- **Количество**: −500 кг
- **Источник**: "Списание на этапе Монтажные работы"
- **Что означает**: Материал использован

### Фильтры:
- 🏢 **Объект** — движения по объекту
- 📦 **Материал** — движения материала
- 🎯 **Тип источника**:
  - Только закупки (приходы)
  - Только списания (расходы)
- 🎯 **Этап** — по этапу работ
- 👤 **Ответственный** — кто создал
- 📅 **Дата с… по…** — период

### Что показывает каждая строка:

**Пример приходной записи:**
```
10.11.2025 | ЖК Солнечный, дом №1 | Цемент М400 | +2000 кг | 
Монтажные работы | Закупка #PUR-2025-0042 | Иванов И.П.
```

**Пример расходной записи:**
```
11.11.2025 | ЖК Солнечный, дом №1 | Цемент М400 | −500 кг | 
Монтажные работы | Списание: Заливка фундамента | Иванов И.П.
```

### Зачем нужен список:
- **Полная история** всех операций с материалами
- **Аудит**: кто, когда, сколько
- **Поиск расхождений** в остатках
- **Проверка** источников движения
- **Отслеживание** цепочки: закупка → использование

**Навигация**: Остатки → По объектам

### Структура списка:

```
📊 Остатки по объектам на 10.11.2025

🏢 Объект: ЖК Солнечный, дом №1
   Адрес: г. Ташкент, мкр Солнечный
   Ответственный: Иванов И.П.

   Материалы (вложенная таблица):
   ┌─────────────────┬───────────┬─────────────┬──────────────┐
   │ Материал        │ Остаток   │ Приход      │ Расход       │
   ├─────────────────┼───────────┼─────────────┼──────────────┤
   │ Цемент М400     │ 1500.0 кг │ 2000.0 кг   │ 500.0 кг     │
   │ Песок речной    │ 8.5 м³    │ 10.0 м³     │ 1.5 м³       │
   │ Арматура 12мм   │ 450.0 м   │ 500.0 м     │ 50.0 м       │
   └─────────────────┴───────────┴─────────────┴──────────────┘

🏢 Объект: ЖК Солнечный, дом №2
   (аналогично)
```

### Колонки вложенной таблицы:

| Колонка | Что показывает | Сортировка |
|---------|----------------|------------|
| **Материал** | Название | ✅ клик на заголовок |
| **Остаток** | Текущий остаток (Приход − Расход) | ✅ |
| **Приход** | Всего закуплено | ✅ |
| **Расход** | Всего списано | ✅ |

### Сортировка вложенной таблицы:
- **По материалу** — алфавитный порядок
- **По остатку** — от большего к меньшему (или наоборот)
- **По приходу** — сколько закупили
- **По расходу** — сколько использовали

**Стрелки показывают направление**: ↑ возрастание, ↓ убывание

### Фильтры:
- 🏢 **Объект** — выбрать конкретный объект
- 📅 **Дата** — остатки на определённую дату
- 🔍 **Поиск** — по названию объекта или материала

### Цветовое кодирование:
- 🟢 **Остаток > 100** — достаточно (зелёный)
- 🟡 **Остаток 1-100** — мало (жёлтый)
- 🔴 **Остаток ≤ 0** — закончился или перерасход (красный)

### Зачем нужен список:
- **Инвентаризация**: что есть на каждом объекте
- **Планирование**: чего нужно докупить
- **Контроль**: нет ли перерасходов
- **Быстрая проверка** без открытия каждого объекта

## 🔄 РАБОТА С ПАГИНАЦИЕЙ

### Где: Внизу любого списка

### Элементы пагинации:

```
Показано 21-40 из 156 записей

[Первая] [Предыдущая] [1] [2] [●3] [4] [5] [Следующая] [Последняя]

На странице: [20 ▼]
```

### Как использовать:

#### Навигация:
- **Первая** — переход на страницу 1
- **Последняя** — переход на последнюю страницу
- **Цифры** — конкретная страница
- **●3** — текущая страница (подсвечена)

#### Размер страницы:
Выпадающий список:
- 10 записей
- 20 записей (по умолчанию)
- 50 записей
- 100 записей

**Когда менять**:
- **10** — для медленного интернета
- **20** — оптимально для работы
- **50-100** — для экспорта большого объёма

## 🔍 ПРОДВИНУТЫЕ ВОЗМОЖНОСТИ

### 1. Комбинирование фильтров

**Пример**: Найти все закупки цемента на объекте "Дом №1" за сентябрь

**Действия**:
1. Откройте "Закупки"
2. Фильтры:
   - Объект: "Дом №1"
   - Дата с: 01.09.2025
   - Дата по: 30.09.2025
3. Поиск: "цемент"
4. Результат: только нужные закупки

### 2. Экспорт с фильтрами

**Совет**: Настройте фильтры → Экспорт → скачается только отфильтрованное

**Пример**:
- Фильтр: Объект = "Дом №1", Месяц = Сентябрь
- Экспорт → Excel
- Результат: файл только с закупками для Дома №1 за сентябрь

### 3. Быстрый переход между связанными данными

**Например, из закупки в остатки**:
1. Открыли закупку → видите материалы
2. Хотите проверить остаток конкретного материала
3. Скопируйте название материала
4. Остатки → По объектам → Поиск → вставьте название
5. Видите текущий остаток этого материала

## 🎯 ТИПИЧНЫЕ ЗАДАЧИ И ГДЕ ИХ РЕШАТЬ

### Задача: Проверить, сколько цемента осталось на объекте

**Решение**:
1. Остатки → По объектам
2. Выберите объект (фильтр или поиск)
3. Найдите "Цемент М400" в таблице материалов
4. Смотрите колонку "Остаток"

---

### Задача: Найти все закупки у конкретного поставщика

**Решение**:
1. Закупки
2. Фильтр: Поставщик = "ООО СтройБаза"
3. Результат: все закупки от этого поставщика

---

### Задача: Сколько потратили на объект за месяц

**Решение**:
1. Отчёты → По объектам
2. Фильтр: 
   - Объект = "Дом №1"
   - Дата с = 01.10.2025
   - Дата по = 31.10.2025
3. Смотрите колонку "Сумма"

---

### Задача: Кто больше всего закупал в этом месяце

**Решение**:
1. Отчёты → По ответственным
2. Фильтр: 
   - Дата с = 01.11.2025
   - Дата по = 30.11.2025
3. Сортировка: по колонке "Закупок" (убывание ↓)
4. Результат: сверху самый активный

---

### Задача: Почему остаток отрицательный

**Решение**:
1. Остатки → Движения
2. Фильтр:
   - Объект = (выберите объект)
   - Материал = (выберите материал с отрицательным остатком)
3. Просмотрите все приходы (+) и расходы (−)
4. Проверьте: может забыли зарегистрировать закупку?

## ❗ ВАЖНЫЕ НАПОМИНАНИЯ

### ⚠️ Красные флаги в списках:

1. **Закупка без фотоотчёта** (статус "Выполнено") → загрузите фото
2. **Отрицательный остаток** → проверьте движения
3. **Неактивный ответственный** → назначьте другого
4. **Архивная запись** → нельзя редактировать

### ✅ Зелёные индикаторы:

1. **Положительный остаток** → материал есть
2. **Фото загружено** → документ подтверждён
3. **Статус "Выполнено"** → закупка завершена
4. **Активен** → запись в работе

## 📞 ПОДДЕРЖКА

### Если не нашли информацию в списке:

1. **Проверьте фильтры** — может быть отфильтровано
