## 📖 О СИСТЕМЕ

**ELOM** (Enterprise Logistics and Operations Management) — это веб-приложение для учёта материалов, закупок, остатков и отчётности на строительных объектах.

### Что умеет система:

✅ **Учёт материалов** — справочник всех стройматериалов  
✅ **Управление закупками** — регистрация поступлений  
✅ **Контроль списаний** — фиксация расхода материалов  
✅ **Остатки в реальном времени** — что и сколько на объекте  
✅ **Отчёты** — 4 типа аналитики с экспортом  
✅ **Автоматизация** — умные подсказки и автозаполнение  
✅ **Telegram-уведомления** — автоматические оповещения  
✅ **Мобильная версия** — работа с телефона/планшета

## 📋 ОСНОВНЫЕ РАЗДЕЛЫ

### 1. 📦 Материалы
**Что это**: Справочник всех материалов (цемент, кирпич, кабель и т.д.)

**Зачем нужно**:
- Создать базу материалов один раз
- Использовать в закупках и списаниях
- Видеть общие остатки

**Когда использовать**:
- Появился новый материал → добавить в справочник
- Нужно проверить остаток материала по всем объектам

**Подробно**: [USER_GUIDE_FORMS.md → Форма материалов](#)

---

### 2. 🏢 Объекты
**Что это**: Строительные объекты (дома, здания, цеха)

**Зачем нужно**:
- Привязать закупки и списания к объекту
- Назначить ответственного бригадира
- Контролировать сроки работ

**Когда использовать**:
- Начали новый объект → зарегистрировать
- Сменился бригадир → обновить ответственного
- Завершили объект → деактивировать

**Подробно**: [USER_GUIDE_FORMS.md → Форма объектов](#)

---

### 3. 🛒 Закупки
**Что это**: Регистрация всех поступлений материалов

**Зачем нужно**:
- Зафиксировать покупку материалов
- Увеличить остатки на объекте
- Контролировать затраты

**Когда использовать**:
- Купили материалы → создать закупку
- Привезли на объект → сменить статус на "Выполнено"
- Нужна отчётность → фильтр и экспорт

**Кто создаёт**: Только **Brigadier** (бригадир)

**Подробно**: [USER_GUIDE_FORMS.md → Форма закупок](#)

---

### 4. 📉 Списания
**Что это**: Фиксация расхода материалов на объекте

**Зачем нужно**:
- Учесть использование материалов
- Уменьшить остатки
- Контролировать расход по этапам работ

**Когда использовать**:
- Использовали материал → создать списание
- Конец рабочего дня → списать израсходованное
- Завершили этап → списать всё использованное

**Кто создаёт**: Только **Brigadier** (бригадир)

**Особенность**: 
- 🎯 Автоматическая фильтрация материалов по объекту
- 🎯 Показывает текущий остаток перед списанием
- 🎯 Автозаполнение единиц измерения

**Подробно**: [USER_GUIDE_FORMS.md → Форма списаний](#)

---

### 5. 📊 Остатки

#### 5.1. Движения (журнал)
**Что это**: Полная история всех операций с материалами

**Зачем нужно**:
- Увидеть все приходы и расходы
- Проверить откуда материал, куда ушёл
- Найти ошибки в учёте

**Когда использовать**:
- Расхождение в остатках → проверить движения
- Нужен аудит → посмотреть историю
- Вопрос "куда делось?" → поиск в движениях

#### 5.2. По объектам
**Что это**: Текущие остатки всех материалов на каждом объекте

**Зачем нужно**:
- Быстро проверить: что и сколько на объекте
- Планировать закупки
- Инвентаризация

**Когда использовать**:
- Перед началом работ → проверить наличие материалов
- Планируете закупку → посмотреть что осталось
- Конец месяца → сверка остатков

**Подробно**: [USER_GUIDE_LISTS.md → Остатки по объектам](#)

---

### 6. 📈 Отчёты

**Что это**: Аналитика и статистика по разным срезам

**4 типа отчётов**:

#### 📊 По периодам
- **Показывает**: Динамику по дням/месяцам
- **Зачем**: Планирование бюджета, тренды
- **Когда**: Еженедельно/ежемесячно

#### 🏗️ По объектам
- **Показывает**: Затраты на каждый объект
- **Зачем**: Сравнение объектов, контроль бюджета
- **Когда**: Еженедельно

#### 📦 По материалам
- **Показывает**: Что закупали, цены, количество
- **Зачем**: Анализ цен, поиск экономии
- **Когда**: Ежемесячно, перед переговорами с поставщиками

#### 👤 По ответственным
- **Показывает**: Статистика работы каждого бригадира
- **Зачем**: Оценка эффективности
- **Когда**: Ежемесячно для премирования

**Все отчёты**: фильтры + сортировка + экспорт в Excel/CSV

**Подробно**: [USER_GUIDE_LISTS.md → Отчёты](#)

---

### 7. 🗄️ Архив

**Что это**: Закрытие периодов для защиты данных

**Зачем нужно**:
- Закрыть месяц → данные нельзя изменить
- Подготовить отчётность
- Защита от случайных изменений

**Кто может закрывать**: Director, Admin, Coordinator  
**Кто может открывать**: Director, Admin

**Когда использовать**:
- Конец месяца → закрыть период
- Ошибка в закрытом периоде → открыть, исправить, закрыть снова

## 🎬 ТИПОВЫЕ СЦЕНАРИИ РАБОТЫ

### Сценарий 1: Утро бригадира

**Время**: 08:00

1. **Вход в систему** → проверка уведомлений
2. **Остатки → По объектам** → проверка что есть на объекте
3. **Планирование**: чего не хватает для сегодняшних работ
4. **Закупки** → создание заявки (если нужна докупка)

---

### Сценарий 2: Получение материалов

**Время**: 12:00, привезли материалы

1. **Закупки → Добавить закупку**
2. Заполнить данные:
   - Объект: мой объект
   - Поставщик: выбрать или создать
   - Материалы: что привезли + количество + цены
3. **Загрузить фото** накладной
4. **Сохранить**
5. **Проверка**: Остатки → По объектам → материалы увеличились

---

### Сценарий 3: Конец рабочего дня

**Время**: 18:00, фиксируем расход

1. **Списания → Добавить списание**
2. Для каждого использованного материала:
   - Объект: мой объект
   - Материал: что использовали
   - Количество: сколько израсходовали
   - Этап: "Монтажные работы" (обычно)
   - Комментарий: где использовали
3. **Сохранить**
4. **Проверка**: Остатки уменьшились

---

### Сценарий 4: Конец месяца (директор)

**Время**: 1 числа следующего месяца

1. **Отчёты → По объектам**
   - Период: прошлый месяц
   - Экспорт → Excel
   - Анализ затрат

2. **Отчёты → По ответственным**
   - Оценка работы бригадиров
   - Кто эффективнее

3. **Архив → Закрыть период**
   - Выбрать объект
   - Выбрать месяц
   - Подтвердить закрытие

4. **Результат**: Данные за месяц защищены от изменений

## 🎯 ЧАСТЫЕ ЗАДАЧИ

### ❓ Как проверить остаток материала на объекте?

**Способ 1** (быстрый):
1. Остатки → По объектам
2. Найти объект (поиск или прокрутка)
3. В таблице материалов найти нужный
4. Смотреть колонку "Остаток"

**Способ 2** (детальный):
1. Остатки → Движения
2. Фильтр: Объект + Материал
3. Увидеть все приходы и расходы
4. Сумма всех движений = текущий остаток

---

### ❓ Как найти конкретную закупку?

**Если знаете номер**:
1. Закупки
2. Поиск: введите номер (например, "0042")
3. Результат сразу

**Если знаете объект и примерную дату**:
1. Закупки
2. Фильтры:
   - Объект: выбрать
   - Дата с… по…
3. Сортировка: по дате (↓ сначала новые)

---

### ❓ Как исправить ошибку в закупке?

**Если период не закрыт**:
1. Закупки → найти закупку
2. Нажать "Редактировать"
3. Исправить данные
4. Сохранить

**Если период закрыт (архив)**:
1. Обратиться к Director/Admin
2. Попросить открыть период
3. Внести исправления
4. Попросить закрыть период снова

---

### ❓ Как узнать, сколько потратили на объект за месяц?

1. Отчёты → По объектам
2. Фильтры:
   - Объект: выбрать нужный
   - Дата с: 01.10.2025
   - Дата по: 31.10.2025
3. Смотреть колонку "Сумма"
4. Экспорт → Excel (если нужен файл)

---

### ❓ Как добавить нового поставщика прямо при создании закупки?

1. Начните создавать закупку
2. В поле "Поставщик" начните вводить название
3. Появится "**+ Создать поставщика**" → кликните
4. Введите минимум:
   - Название
   - Телефон (желательно)
5. Поставщик сохранится автоматически
6. Продолжите оформление закупки

## 🛠️ ПОЛЕЗНЫЕ ФУНКЦИИ

### 🔍 Поиск (в любом списке):

**Как работает**:
1. Вводите текст в строку поиска
2. Через 0.3 секунды — результат
3. Поиск идёт по нескольким полям сразу

**Примеры**:
- В материалах: ищет по названию, артикулу, описанию
- В закупках: ищет по номеру, поставщику, комментарию
- В объектах: ищет по названию, адресу

### 📊 Сортировка:

**Как использовать**:
- Клик на заголовок колонки → сортировка по возрастанию (↑)
- Ещё клик → по убыванию (↓)
- Ещё клик → отмена сортировки

**Советы**:
- Сортируйте по "Дата" → увидите последние операции
- Сортируйте по "Сумма" → увидите самые дорогие
- Сортируйте по "Остаток" → найдёте что заканчивается

### 📥 Экспорт:

**Форматы**:
- **CSV** — для импорта в другие системы
- **Excel** — готовая таблица для работы
- **PDF** — для печати *(скоро)*

**Что экспортируется**:
- Только то, что видите после фильтрации
- Все колонки таблицы
- С текущей сортировкой

**Как использовать**:
1. Настройте фильтры (если нужна выборка)
2. Нажмите "Экспорт"
3. Выберите формат
4. Файл скачается автоматически

### 🎨 Темы:

**Переключение темы**: Иконка 🌙/☀️ в правом верхнем углу

- **Светлая** — для работы днём
- **Тёмная** — для работы вечером/ночью
- **Системная** — автоматически по времени суток

4. **Не забывайте указывать цены** — нужны для анализа

## 🆘 РЕШЕНИЕ ПРОБЛЕМ

### Проблема: Не вижу объект в списке

**Возможные причины**:
1. Объект не назначен вам → обратитесь к администратору
2. Объект деактивирован → фильтр "Только активные"
3. Вы не на той странице → проверьте пагинацию

**Решение**:
- Сбросьте фильтры
- Проверьте "Активность" → выберите "Все"
- Используйте поиск по названию

---

### Проблема: Список пустой

**Возможные причины**:
1. Действительно нет данных → создайте первую запись
2. Слишком строгие фильтры → сбросьте
3. Не загрузились данные → обновите страницу (F5)

**Решение**:
1. Кнопка "Сбросить фильтры"
2. Обновить страницу (F5)
3. Проверить интернет-соединение

### Проблема: Не могу редактировать/удалить запись

**Возможная причина**: Запись в архиве

**Решение**:
- Проверьте колонку "Архив"
- Если архив → обратитесь к Director для открытия периода
- Если не архив → проверьте права доступа

---

### Проблема: Отрицательный остаток материала (−150 кг)

**Что это означает**: Списали больше, чем закупили (перерасход)

**Возможные причины**:
1. Забыли зарегистрировать закупку
2. Ошибка в количестве при списании
3. Материал перенесли с другого объекта (не учли)

**Решение**:
1. Остатки → Движения → фильтр по объекту и материалу
2. Проверьте все приходы (+) и расходы (−)
3. Найдите пропущенную закупку или ошибочное списание
4. Создайте корректирующую закупку или удалите ошибочное списание
