# Анализ связей архива с остальными компонентами системы

## Общая схема связей

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Archive       │    │   Purchases     │    │   StockSnapshots│
│   Periods       │◄──►│   (Закупки)     │◄──►│   (Снимки)      │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         │                       │                       │
         ▼                       ▼                       ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Objects       │    │   Materials     │    │   WriteOffs     │
│   (Объекты)     │    │   (Материалы)   │    │   (Списания)    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## Детальные связи

### 1. **Архив ↔ Закупки (Purchases)**

**Backend связи:**
- `Purchase.is_archived: boolean` - флаг архивирования
- При создании `ArchivePeriod` автоматически архивируются все закупки за период
- Сигнал `archive_period_created` в `stock/signals.py`

**Frontend связи:**
- `stores/purchases.ts`: функции `activePurchases` и `archivedPurchases`
- `pages/Purchases/List.vue`: отображение бейджа "Архив" для заархивированных закупок
- `components/cards/PurchaseCard.vue`: показ статуса архивирования

### 2. **Архив ↔ Складские снимки (StockSnapshots)**

**Backend связи:**
- `StockSnapshot.is_archived: boolean` - флаг архивирования
- Автоматическое архивирование при создании архивного периода
- Связь через `object` и `date` поля

**Frontend связи:**
- `pages/Stocks/List.vue`: фильтр по архивированным снимкам
- `api/types/stocks.ts`: типы с полем `is_archived`

### 3. **Архив ↔ Объекты (Objects)**

**Backend связи:**
- `ArchivePeriod.object` - связь с объектом
- Уникальность по `(month, object)` - один период на объект в месяц
- Индексы для быстрого поиска

**Frontend связи:**
- `pages/Archive/ListWorking.vue`: выбор объекта при закрытии периода
- `stores/objects.ts`: получение списка объектов для архива

### 4. **Архив ↔ Пользователи (Users)**

**Backend связи:**
- `ArchivePeriod.closed_by` - кто закрыл период
- Автоматическое архивирование через системного пользователя

**Frontend связи:**
- Отображение имени пользователя, закрывшего период
- Аватары и инициалы в интерфейсе

## Frontend интеграция

### 1. **Отображение архивного статуса**
- **Закупки**: бейдж "Архив" в списке и карточках
- **Склад**: фильтр по архивированным снимкам
- **Архив**: статистика и управление периодами

### 2. **Фильтрация данных**
- `activePurchases` - только неархивированные закупки
- `archivedPurchases` - только архивированные закупки
- Фильтр `is_archived` в складских операциях

### 3. **Управление архивами**
- Закрытие периодов через модальное окно
- Открытие периодов с подтверждением
- Статистика по архивным периодам

## API Endpoints

### Archive API
- `GET /api/v1/archive/periods/` - список периодов
- `POST /api/v1/archive/periods/close/` - закрыть период
- `POST /api/v1/archive/periods/reopen/` - открыть период

### Связанные API
- `GET /api/v1/purchases/?is_archived=true` - архивированные закупки
- `GET /api/v1/stocks/?is_archived=true` - архивированные снимки
- `GET /api/v1/objects/` - объекты для архива

## Автоматизация

### 1. **Django Signals**
- Автоматическое архивирование при создании периода
- Предотвращение удаления архивных периодов
- Логирование операций архивирования

### 2. **Celery Tasks**
- `auto_archive_old_periods_task` - автоматическое архивирование
- `check_archive_integrity_task` - проверка целостности
- `cleanup_old_archives_task` - очистка старых архивов

### 3. **Management Commands**
- `archive_period` - ручное архивирование
- `list_archives` - просмотр архивов

### 2. **Оптимизация запросов**

- Фильтрация по архивированным данным

### 3. **Кэширование**
- Статистика архивных периодов
- Списки объектов и пользователей
- Результаты фильтрации

### 1. **Права на архивирование**
- Только авторизованные пользователи
- Проверка прав на объекты
- Аудит операций архивирования

### 2. **Защита данных**
- Предотвращение удаления архивных периодов
- Проверка целостности данных

### 3. **Восстановление**

- Откат архивирования
- Восстановление данных

## Заключение

Архив является центральным компонентом системы, который:

1. **Интегрируется** с закупками, складскими операциями и объектами
2. **Автоматизирует** процесс архивирования через сигналы и задачи
3. **Обеспечивает** целостность данных и производительность
4. **Предоставляет** удобный интерфейс для управления архивами
5. **Защищает** данные от случайного удаления и обеспечивает аудит

Система архива полностью интегрирована в общую архитектуру приложения и готова к продакшену.
