## 🔧 Недавние исправления

### Проблемы решены

#### 1. Постоянное обновление таблиц
**Проблема**: Таблица на странице Balances постоянно обновлялась
**Причина**: Реактивность filters в computed свойстве
**Решение**: Refactoring на прямое использование store

#### 2. Неверная пагинация
**Проблема**: Отображение некорректного количества записей
**Причина**: Замена объекта pagination вместо обновления свойств
**Решение**: Обновление свойств существующего объекта

#### 3. Пустое поле материалов в WriteOffForm
**Проблема**: Материалы не отображались в селекте
**Причина**: Потеря реактивности при использовании `:key`
**Решение**: Удаление `:key`, добавление `v-if` для условного рендеринга

#### 4. Сброс поля объекта при выборе
**Проблема**: Поле объекта сбрасывалось при выборе
**Причина**: Пересоздание формы из-за `:key` атрибута
**Решение**: Удаление `:key`, использование `v-if` для управления рендерингом

#### 5. Неправильная обработка ошибок API
**Проблема**: Ошибки отображались как `object[0]` вместо `object`
**Причина**: Некорректный парсинг простых массивов ошибок
**Решение**: Улучшение функции `parseNestedErrors`

#### 6. Данные не загружались при редактировании
**Проблема**: При редактировании списания материалы не загружались
**Причина**: Отсутствие вызовов `loadMaterialsByObject` и `loadEmployeesByObject`
**Решение**: Асинхронная инициализация формы с загрузкой данных

#### 7. TypeError: useWriteOffsStore is not a function
**Проблема**: Store не был функцией
**Причина**: `createBaseStore` возвращал определение вместо вызова
**Решение**: Изменение `return store` на `return store()`
