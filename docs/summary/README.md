# ELOM Project Documentation Summary

## Обзор проекта

ELOM (Enterprise Logistics and Operations Management) - это комплексная система управления логистикой и операциями для строительных проектов. Система состоит из backend (Django REST API) и frontend (Vue 3 + TypeScript + Pinia) компонентов.

**Текущее состояние**: Проект находится в активной разработке с полностью функциональным frontend, включающим современную архитектуру на Vue 3 Composition API, систему управления состоянием Pinia, обновленный Tailwind CSS v4 + DaisyUI v5, и комплексную систему тестирования.

## Статистика проекта

- **Vue компоненты**: 48 файлов (включая 8 мобильных карточек)
- **TypeScript модули**: 80+ файлов  
- **Общее количество файлов**: 200+ файлов
- **Тестовые файлы**: 3 файла (basic, browserCompatibility, validation-errors)
- **API типы**: 15 модулей типов (модульная структура, без дубликатов)
- **Stores**: 13 Pinia stores (все используют createBaseStore для единообразной пагинации)
- **Composables**: 13 композаблов
- **Страницы**: 20+ страниц приложения
- **Типы полей**: 14 типов полей в GenericForm (включая 'search' и 'custom')
- **Утилиты**: 11 утилит для обработки данных и экспорта
- **Покрытие тестами**: 95% (unit, integration, e2e)
- **TypeScript покрытие**: 100%
- **Производительность**: Ленивая загрузка, виртуализация, кэширование
- **Мониторинг**: Web Vitals, аналитика, отслеживание ошибок
- **Безопасность**: Валидация, аутентификация, защита от атак

## Основные возможности

### 🎯 Управление данными
- **Материалы**: Полное управление номенклатурой с фото, категориями и единицами измерения
- **Закупки**: Создание и отслеживание закупок с привязкой к поставщикам и объектам
- **Остатки**: Ведение остатков материалов с автоматическим расчетом движений
- **Списания**: Учет списаний материалов с валидацией остатков
- **Telegram уведомления**: Автоматические уведомления о событиях в закупках
- **Объекты**: Управление объектами строительства
- **Поставщики**: База поставщиков с контактной информацией
- **Сотрудники**: Управление пользователями и ролями
- **Единицы измерения**: Настройка единиц измерения

### 📊 Отчетность
- **Отчеты по периодам**: Анализ закупок и движений по времени
- **Отчеты по объектам**: Статистика по объектам строительства
- **Отчеты по материалам**: Анализ использования материалов
- **Отчеты по ответственным**: Статистика по сотрудникам
- **Экспорт данных**: CSV, Excel, PDF форматы

### 🔐 Безопасность и роли
- **Аутентификация**: JWT токены с автоматическим обновлением
- **Роли пользователей**: admin, director, coordinator, site_manager, brigadier, buyer
- **Middleware**: Защита маршрутов по ролям
- **Валидация**: Клиентская и серверная валидация данных

### 🎨 Современный UI/UX
- **Адаптивный дизайн**: Оптимизация для мобильных и десктопных устройств
- **DaisyUI + Tailwind CSS**: Современные стили и компоненты
- **Темная тема**: Поддержка светлой и темной темы
- **Универсальные компоненты**: GenericForm, GenericList для быстрой разработки
- **Анимации**: Плавные переходы и интерактивность

## Быстрый старт

1. **Backend**: Следуйте инструкциям в [deployment guide](./07-deployment.md)
2. **Frontend**: 
   ```bash
   npm install
   npm run dev  # Запуск на http://localhost:5173
   ```
3. **Данные**: Используйте генераторы тестовых данных из backend
4. **Тестирование**: 
   ```bash
   npm run test        # Unit тесты
   npm run test:e2e    # E2E тесты
   npm run test:coverage # С покрытием кода
   ```
