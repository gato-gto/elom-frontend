# Исправления Frontend Архива

## Проблемы, которые были исправлены

### 1. Дублирующие функции экспорта
**Проблема**: В `src/utils/export.ts` были дублирующие функции `exportToCSV`, `exportToExcel`, `exportToPDF`
**Решение**: Удален дублирующий код, оставлены только оригинальные функции

### 2. Неправильные импорты в List.vue
**Проблема**: 
- Импорт `useUiStore` который не имеет метода `confirm`
- Неправильный импорт функций экспорта
**Решение**: 
- Заменен `uiStore.confirm` на простой `confirm()`
- Исправлен импорт на `useExport` composable
- Удален неиспользуемый импорт `useUiStore`

### 3. Store архива использует fetch вместо api client
**Проблема**: Store использовал нативный `fetch` вместо настроенного `api` client
**Решение**: Заменен на использование `api` client и `endpoints`

### 4. Сложные зависимости в List.vue
**Проблема**: List.vue имел много сложных зависимостей и мог не работать
**Решение**: Создана упрощенная версия `ListWorking.vue` с:
- Прямыми API вызовами
- Простыми типами без сложных импортов
- Базовым функционалом без излишних зависимостей

## Файлы, которые были изменены

1. **`src/utils/export.ts`** - удален дублирующий код
2. **`src/pages/Archive/List.vue`** - исправлены импорты и использование composables
3. **`src/stores/archive.ts`** - заменен fetch на api client
4. **`src/pages/Archive/ListWorking.vue`** - создана новая рабочая версия
5. **`src/router/index.ts`** - обновлен для использования ListWorking.vue
