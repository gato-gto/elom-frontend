## ✨ Новые функции

### 1. Фильтрация материалов по остаткам в форме списаний

**Файлы:**
- `src/components/MaterialSearchSelect.vue`
- `src/pages/WriteOffs/WriteOffForm.vue`

**Описание:**
Добавлена автоматическая фильтрация материалов при поиске в форме списаний. Теперь в автодополнении показываются только те материалы, которые есть в наличии (остаток > 0) на выбранном объекте.

**Технические детали:**
- Добавлены новые props в `MaterialSearchSelect`:
  - `objectId` - ID объекта для фильтрации
  - `date` - Дата для проверки остатков
  - `filterByBalance` - Флаг включения фильтрации
- При поиске материалов выполняется запрос к API `/stock/snapshots/by-objects/` для получения остатков
- Результаты поиска фильтруются, оставляя только материалы с `current_balance > 0`
- Если объект не выбран или фильтрация отключена, показываются все результаты поиска

**Преимущества:**
- Пользователи видят только доступные материалы
- Снижается вероятность ошибок при выборе материалов без остатков
- Улучшается UX при работе с формой списаний

### 2. Удаление колонки "Этап" из списка списаний

**Файлы:**

**Описание:**
