# 📊 API ВОЗМОЖНОСТИ ДЛЯ ОТЧЕТОВ - ELOM

## 🎯 **ОБЗОР СИСТЕМЫ ОТЧЕТОВ**

Система отчетов ELOM предоставляет 4 основных типа отчетов с возможностью экспорта в Excel и PDF форматы. Все отчеты работают с данными закупок и поддерживают гибкую фильтрацию.

---

## 📋 **ДОСТУПНЫЕ ТИПЫ ОТЧЕТОВ**

### 1. 📅 **Отчет по периодам** (`/reports/purchases/by-period/`)
**Описание:** Группировка сумм и количества закупок по дню или месяцу

**Параметры:**
- `period` - тип группировки: `"day"` | `"month"` (по умолчанию: `"month"`)
- `date_from` - дата начала (YYYY-MM-DD)
- `date_to` - дата окончания (YYYY-MM-DD)
- `object` - массив ID объектов (множественный: `?object=1&object=2`)
- `responsible` - ID ответственного
- `is_archived` - фильтр по архивным данным (`true`|`false`)
- `export` - формат экспорта (`"xlsx"`|`"pdf"`)

**Пример ответа:**
```json
{
  "rows": [
    {
      "period": "2025-09",
      "purchases": 12,
      "total_amount": 3450000.0
    },
    {
      "period": "2025-10", 
      "purchases": 8,
      "total_amount": 1250000.0
    }
  ]
}
```

### 2. 🏢 **Отчет по объектам** (`/reports/purchases/by-object/`)
**Описание:** Агрегация закупок по объектам строительства

**Параметры:**
- `date_from` - дата начала (YYYY-MM-DD)
- `date_to` - дата окончания (YYYY-MM-DD)
- `object` - массив ID объектов (множественный)
- `responsible` - ID ответственного
- `is_archived` - фильтр по архивным данным
- `export` - формат экспорта (`"xlsx"`|`"pdf"`)

**Пример ответа:**
```json
{
  "rows": [
    {
      "object_id": 1,
      "object_name": "Объект А",
      "purchases": 7,
      "total_amount": 980000.0
    },
    {
      "object_id": 2,
      "object_name": "Объект Б", 
      "purchases": 3,
      "total_amount": 270000.0
    }
  ]
}
```

**Параметры:**

- `object` - массив ID объектов (множественный)
- `responsible` - ID ответственного
- `is_archived` - фильтр по архивным данным
- `export` - формат экспорта (`"xlsx"`|`"pdf"`)

**Пример ответа:**
```json
{
  "rows": [

      "responsible_id": 3,
      "responsible_name": "Aziz I.",
      "purchases": 6,
      "total_amount": 750000.0

      "responsible_name": "Javlon R.",

      "total_amount": 520000.0

```

### 4. 📦 **Отчет по материалам** (`/reports/purchases/by-material/`)
**Описание:** Агрегация по материалам с конвертацией количества к базовой единице

**Параметры:**
- `date_from` - дата начала (YYYY-MM-DD)
- `date_to` - дата окончания (YYYY-MM-DD)
- `object` - массив ID объектов (множественный)
- `responsible` - ID ответственного
- `material` - ID конкретного материала
- `is_archived` - фильтр по архивным данным
- `export` - формат экспорта (`"xlsx"`|`"pdf"`)

**Пример ответа:**
```json
{
  "rows": [
    {
      "material_id": 5,
      "material_name": "Кабель ВВГ",
      "unit": "м",
      "qty_total": 150.0,
      "amount_total": 3750000.0,
      "rows": 12
    },
    {
      "material_id": 9,
      "material_name": "Автомат 16A",
      "unit": "шт", 
      "qty_total": null,
      "amount_total": 820000.0,
      "rows": 7
    }
  ]
}
```

## 🔧 **ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ**

### **Авторизация и доступ**
- ✅ **JWT аутентификация** - все endpoints требуют токен
- ✅ **Ролевая фильтрация** - данные ограничены по ролям пользователей
- ✅ **Область видимости** - директор/координатор видят все, остальные - только свои объекты

### **Умная конвертация единиц**
- ✅ **Автоматическая конвертация** - количества приводятся к базовой единице материала
- ✅ **Обработка ошибок** - если конвертация невозможна, `qty_total` = `null`
- ✅ **Точность расчетов** - используется Decimal для финансовых операций

### **Производительность**
- ✅ **Оптимизированные запросы** - `select_related` для связанных объектов
- ✅ **Пагинация** - поддержка больших объемов данных
- ✅ **Кэширование** - эффективная работа с базой данных

## 🎨 **FRONTEND ИНТЕГРАЦИЯ**

### **Компоненты отчетов**
- ✅ **4 страницы отчетов** - `ByPeriod.vue`, `ByObject.vue`, `ByResponsible.vue`, `ByMaterial.vue`
- ✅ **Единый дизайн** - использование `ListHeader`, `FilterPanel`, `FilterField`
- ✅ **Экспорт кнопки** - прямые ссылки на Excel/PDF экспорт
- ✅ **Фильтрация** - интерактивные фильтры с debounce

### **Типизация TypeScript**
```typescript
// Интерфейсы для всех типов отчетов
export interface ReportByPeriodQuery {
  date_from?: string;
  date_to?: string;
  export?: "pdf" | "xlsx";
  is_archived?: boolean;
  object?: ID[];
  period?: "day" | "month";
  responsible?: ID;
}

export interface ReportResponse {
  rows: (string | number | null)[][];
}
```

### **API клиент**
```typescript
// Endpoints для всех отчетов
reports: {
  byPeriod: join('/reports/purchases/by-period/'),
  byObject: join('/reports/purchases/by-object/'),
  byResponsible: join('/reports/purchases/by-responsible/'),
  byMaterial: join('/reports/purchases/by-material/'),
}
```

## 📊 **ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ**

### **1. Получить отчет по периодам за сентябрь 2025**
```http
GET /api/v1/reports/purchases/by-period/?date_from=2025-09-01&date_to=2025-09-30&period=day
Authorization: Bearer {token}
```

### **2. Экспорт отчета по объектам в Excel**
```http
GET /api/v1/reports/purchases/by-object/?export=xlsx&object=1&object=2&responsible=5
Authorization: Bearer {token}
```

### **3. Отчет по материалам с фильтрацией**
```http
GET /api/v1/reports/purchases/by-material/?material=10&is_archived=false&date_from=2025-01-01
Authorization: Bearer {token}
```

### **4. Отчет по ответственным за период**
```http
GET /api/v1/reports/purchases/by-responsible/?date_from=2025-01-01&date_to=2025-12-31&object=1
Authorization: Bearer {token}
```
