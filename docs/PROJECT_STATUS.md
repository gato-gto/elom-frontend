## 🆕 Последние обновления (ноябрь 2025)

### Оптимизация ролей (27 ноября):
1. **Упрощение системы ролей** - оставлены 4 роли: admin, director, coordinator, brigadier
2. **Удаление buyer/site_manager** - их функции теперь выполняет brigadier
3. **Миграция данных** - автоматическая конвертация существующих пользователей
4. **Backend** - суперпользователи скрыты из API списка сотрудников
5. **Frontend** - обновлены формы, списки, фильтры ролей

### Защита от деактивированных объектов (27 ноября):
1. **Запрет операций** - нельзя создавать закупки и списания для деактивированных объектов
2. **Фильтрация в формах** - деактивированные объекты скрыты в выпадающих списках
3. **Backend валидация** - проверка `is_active` при создании закупок и списаний
4. **Frontend фильтрация** - `objectOptions` фильтрует только активные объекты

### Безопасное удаление объектов (27 ноября):
1. **Защита от удаления** - объекты со связями (закупки, списания, движения) не удаляются
2. **Деактивация** - вместо удаления объект помечается как `is_active=false`
3. **Информирование пользователя** - уведомление о деактивации вместо удаления
4. **Скрытие кнопки** - кнопка "Удалить" скрыта для деактивированных объектов
5. **Аудит** - действие `deactivate` записывается в журнал аудита

### Бизнес-логика статусов закупок (26-27 ноября):
1. **Только `completed` закупки** - учитываются в остатках и отчётах
2. **Статусы `new` и `cancelled`** - не создают записи в StockSnapshot
3. **Синхронизация при смене статуса** - автоматическое создание/удаление записей
4. **Фильтрация материалов** - endpoint `by-object` возвращает только из выполненных закупок
5. **Отчёты** - по умолчанию включают только выполненные закупки

### Функциональность бригадира (26-27 ноября):
1. **Объекты** - бригадир видит только свои объекты, может создавать новые
2. **Автоназначение** - при создании объекта бригадир автоматически становится ответственным
3. **Блокировка ответственного** - бригадир не может сменить ответственного за объект
4. **Списания** - поле "Ответственный" заблокировано, автовыбор единственного объекта
5. **Подсказки материалов** - исключение уже добавленных материалов из подсказок
6. **Уведомления** - toast при успешном/неуспешном сохранении списания

### Рефакторинг:
1. **PurchaseForm.onSaved()** - разбит на 5 функций (-81% кода)
2. **useItemsForm composable** - устранено 380 строк дублирования
3. **GenericSearchSelect** - устранено 400 строк дублирования
4. **Система валидаторов** - 9 переиспользуемых валидаторов
