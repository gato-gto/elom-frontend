# Анализ состояния раздела Архив

## Обзор

Раздел "Архив" предназначен для управления закрытыми периодами по объектам. Позволяет архивировать данные закупок и складских операций за определенные месяцы, делая их read-only.

## Текущее состояние разработки

### ✅ Реализовано (Frontend)

#### 1. Компоненты
- **`src/pages/Archive/List.vue`** - основная страница архива
- **Навигация** - интегрирован в роутер и навигацию
- **Типы** - `src/api/types/archive.ts` с полным набором интерфейсов

#### 2. Функциональность
- **Просмотр архивных периодов** - таблица с фильтрацией и сортировкой
- **Закрытие периодов** - модальное окно для закрытия месяца по объекту
- **Открытие периодов** - возможность отменить архивирование
- **Экспорт данных** - CSV, Excel, PDF
- **Фильтрация** - по месяцу и объекту

#### 3. UI/UX
- **GenericList интеграция** - использует стандартный компонент
- **Мобильная поддержка** - адаптивный дизайн
- **Статусы** - визуальные индикаторы закрытых периодов
- **Действия** - кнопки для открытия/закрытия периодов

### ✅ Реализовано (Backend)

#### 1. Модели
- **`ArchivePeriod`** - модель закрытых периодов
- **Связи** - с Object и User
- **Уникальность** - по комбинации month + object

#### 2. API Endpoints
- **`GET /archive/periods/`** - список архивных периодов
- **`POST /archive/close/`** - закрытие периода
- **`POST /archive/reopen/`** - открытие периода
- **Фильтрация** - по месяцу, объекту, пользователю
- **Сортировка** - по месяцу, дате закрытия

#### 3. Бизнес-логика
- **Массовое архивирование** - закупки и складские операции
- **Права доступа** - контроль по ролям и объектам
- **Аудит** - логирование операций архивирования
- **Транзакции** - атомарность операций
