## 📋 Текущий процесс настройки

### Шаг 1: Создание бота
1. Открыть @BotFather в Telegram
2. Выполнить команду `/newbot`
3. Ввести имя и username бота
4. Получить `bot_token`

### Шаг 2: Получение Chat ID
1. Добавить бота в группу или начать диалог
2. Отправить любое сообщение
3. Выполнить запрос: `https://api.telegram.org/bot<TOKEN>/getUpdates`
4. Найти `chat_id` в ответе

### Шаг 3: Настройка в системе
1. Войти в Django Admin (`/admin/`)
2. Перейти в раздел "Purchases" → "Telegram Settings"
3. Создать новую запись:
   - Ввести `bot_token`
   - Ввести `chat_id`
   - Установить `is_active = True`
4. Сохранить

### Шаг 4: Проверка работы
1. Создать тестовую закупку
2. Проверить получение уведомления в Telegram
3. Проверить запись в "Telegram Notifications" в админке
