```typescript
// composables/useThemeColors.ts
export function useThemeColors() {
  const themeStore = useThemeStore()
  
  return {
    // Базовые цвета
    background: computed(() => themeStore.isDark ? 'base-200' : 'base-100'),
    surface: computed(() => themeStore.isDark ? 'base-300' : 'base-200'),
    text: computed(() => themeStore.isDark ? 'base-content' : 'base-content'),
    
    // Семантические цвета
    primary: 'primary',
    secondary: 'secondary',
    accent: 'accent',
    error: 'error',
    success: 'success',
    warning: 'warning',
    info: 'info',
  }
}
```

## 🔧 Технические детали

### Цветовая система DaisyUI

**Базовые цвета:**
- `base-100` - основной фон
- `base-200` - вторичный фон
- `base-300` - третичный фон
- `base-content` - основной текст

**Семантические цвета:**
- `primary` - основной цвет (фиолетовый)
- `secondary` - вторичный цвет
- `accent` - акцентный цвет
- `neutral` - нейтральный цвет
- `info` - информационный (голубой)
- `success` - успех (зеленый)
- `warning` - предупреждение (желтый)
- `error` - ошибка (красный)

### Маппинг цветов

| Tailwind | DaisyUI Light | DaisyUI Dark |
|----------|---------------|--------------|
| gray-50  | base-200      | base-300     |
| gray-100 | base-200      | base-300     |
| gray-200 | base-300      | base-300     |
| gray-300 | base-300      | base-300     |
| gray-400 | base-content/70 | base-content/70 |
| gray-500 | base-content  | base-content |
| gray-600 | base-content  | base-content |
| gray-700 | base-content  | base-content |
| gray-800 | base-content  | base-content |
| gray-900 | base-content  | base-content |
| blue-*   | primary-*     | primary-*    |
| red-*    | error-*       | error-*      |
| green-*  | success-*     | success-*    |
| yellow-* | warning-*     | warning-*    |
| cyan-*   | info-*        | info-*       |

## 🎨 Примеры миграции

### До:
```vue
<div class="bg-gray-100 text-gray-800 border-gray-300">
  <button class="bg-blue-500 hover:bg-blue-600 text-white">
    Кнопка
  </button>
</div>
```

### После:
```vue
<div class="bg-base-200 text-base-content border-base-300">
  <button class="btn btn-primary">
    Кнопка
  </button>
</div>
```

### С dark mode:
```vue
<div class="bg-base-200 dark:bg-base-300 text-base-content border-base-300">
  <button class="btn btn-primary">
    Кнопка
  </button>
</div>
```

## ⚠️ Важные замечания

1. **Не удалять все gray-* цвета:**
   - Некоторые случаи требуют точных оттенков gray
   - Использовать только когда действительно нужно

2. **Сохранять обратную совместимость:**
   - Миграция должна быть постепенной
   - Не ломать существующий функционал

3. **Тестировать на реальных данных:**
   - Проверять с реальным контентом
   - Учитывать длинные тексты
   - Проверять контрастность

4. **Документировать изменения:**
   - Коммиты должны быть понятными
