# 🔧 Исправление кнопки "Открыть" на странице закупок

## ❌ **ПРОБЛЕМА**

**Описание:** Кнопка "Открыть" на странице закупок не работала.

**Симптомы:**
- При нажатии на кнопку "Открыть" ничего не происходило
- Пользователь не мог открыть закупку для просмотра/редактирования

---

## 🔍 **ДИАГНОСТИКА**

### **1. Проверка маршрутизации**

**Проблема найдена:** Неправильный маршрут в кнопке.

#### **БЫЛО:**
```vue
<RouterLink class="btn btn-xs btn-outline" :to="`/purchases/${p.id}`">Открыть</RouterLink>
```

#### **ПРОБЛЕМА:**
- Кнопка вела на `/purchases/{id}`
- Но в роутере настроен только `/purchases/{id}/edit`

#### **МАРШРУТЫ В РОУТЕРЕ:**
```typescript
// ❌ НЕТ маршрута для просмотра
// path: '/purchases/:id' - НЕ СУЩЕСТВУЕТ

// ✅ ЕСТЬ только для редактирования
{
  path: '/purchases/:id/edit',
  name: 'PurchaseEdit',
  component: PurchaseForm,
  meta: { 
    title: 'Редактировать закупку',
    breadcrumb: 'Закупки / Редактировать'
  }
}
```

### **2. Проверка бэкенда**

**✅ Бэкенд поддерживает получение закупки:**
- Endpoint: `GET /api/v1/purchases/{id}/`
- ViewSet: `PurchaseViewSet` с методом `retrieve`
- Сериализатор: `PurchaseSerializer`

### **3. Проверка фронтенда**

**✅ Логика загрузки работает:**
- `PurchaseForm.vue` правильно определяет режим редактирования
- `purchasesStore.fetchOne()` существует
- Обработка ошибок настроена

---

## ✅ **РЕШЕНИЕ**

### **Исправление маршрута**

**ИЗМЕНИЛИ:**
```vue
<!-- БЫЛО -->
<RouterLink class="btn btn-xs btn-outline" :to="`/purchases/${p.id}`">Открыть</RouterLink>

<!-- СТАЛО -->
<RouterLink class="btn btn-xs btn-outline" :to="`/purchases/${p.id}/edit`">Открыть</RouterLink>
```

**РЕЗУЛЬТАТ:**
- Кнопка теперь ведет на правильный маршрут `/purchases/{id}/edit`
- Форма закупки открывается в режиме редактирования
- Пользователь может просматривать и редактировать закупку
