## 1. ЦЕЛЬ ПРОЕКТА

Создать удобный веб-инструмент (сайт/мини-приложение/внутренний сервис), который заменит текущую Google-таблицу для:

- **учёта закупленных материалов**
- **переноса данных в архив**
- **контроля остатков на объектах**
- **формирования отчётов** по периодам, объектам, материалам и ответственным

---

## 2. РОЛИ И ДОСТУПЫ ПОЛЬЗОВАТЕЛЕЙ

### 2.1. Иерархия ролей

| Роль | Доступ | Описание |
|------|--------|----------|
| **Директор** | Полный доступ | Настройка справочников, все операции |
| **Координатор** | Полный просмотр | Без редактирования/удаления |
| **Бригадир** | Свои объекты | CRUD закупок и остатков, добавление материалов |
| **Закупщик/Мастер** | Свои объекты | Внесение закупок |
| **Ответственный на объекте** | Свои объекты | Внесение фактических остатков |
| **Руководитель** | Read-only | Только отчёты и архив |

### 2.2. Особенности доступа

- **Закрепление объектов**: каждый объект закреплён за бригадиром
- **Видимость данных**: директор/координатор видят всё
- **Автоматические уведомления**: заявки на закупку автоматически отправляются в группу поставщиков
- **Уведомления об ошибках**: бригадиры получают уведомления при ошибках/правках

## 3. ОБЪЕКТЫ И СКЛАД

### 3.1. Объект (стройплощадка)

**Поля объекта:**
- Название
- Адрес/координаты
- Ответственный (бригадир)
- Даты начала/окончания
- Кабельный журнал
- Статус (активный/неактивный)

### 3.2. Склад

**Типы складов:**
- Центральный склад
- Объектные склады
- Поддержка перемещений между объектами

**Учёт:**
- Закупки материалов
- Расход материалов
- Остатки по этапам работ

---

## 4. МАТЕРИАЛЫ И ЕДИНИЦЫ ИЗМЕРЕНИЯ

### 4.1. Карточка материала

**Обязательные поля:**
- Название
- SKU (артикул)
- Категория (иерархическая)
- Единица измерения (базовая)
- Фото (опционально)

### 4.2. Управление материалами

- **Полный список материалов** предоставляется
- **Редактирование**: бригадиры и выше
- **Конвертации единиц**: мешок ↔ кг, м ↔ см и т.д.
- **Иерархические категории**: строительные материалы → кирпич → красный кирпич

## 5. ОСНОВНОЙ ФУНКЦИОНАЛ

### 5.1. Закупки

#### 5.1.1. Многопозиционная форма закупки

**Поля закупки:**
- Дата закупки
- Объект
- Поставщик
- Номер чека/накладной
- НДС (включён/не включён)
- Валюта (UZS)
- Ответственный
- Комментарий

**Поля позиции:**
- Материал
- Количество
- Единица измерения
- Цена за единицу
- Сумма позиции

**Дополнительно:**
- Фото/документы (несколько файлов)
- Автоматический расчёт общей суммы

#### 5.1.2. Права доступа к закупкам

- **Бригадиры**: CRUD только своих объектов
- **Директор/Координатор**: CRUD всех закупок
- **Закупщик/Мастер**: создание закупок для своих объектов

### 5.2. Архивация

#### 5.2.1. Закрытие периодов

**Процесс:**
1. "Закрыть список" → данные переходят в архив
2. Архивные данные становятся read-only
3. Возможность открытия периода (только директор/координатор)

**Права:**
- **Директор/Координатор**: закрытие всех периодов
- **Бригадиры**: закрытие только своих объектов

#### 5.2.2. Архив

**Функции:**
- Поиск по любому полю
- Фильтрация по периодам, объектам, материалам
- Просмотр архивных данных
- Экспорт архивных данных

### 5.3. Остатки

#### 5.3.1. Форма фиксации остатков

**Поля:**
- Дата фиксации
- Объект
- Материал
- Остаток фактический
- Единица измерения
- Ответственный
- Этап работ
- Комментарий

#### 5.3.2. Этапы работ

1. **Приём объекта** → начальные остатки
2. **Заявка** → планируемые закупки
3. **Закуп** → поступление материалов
4. **Остатки после черновых работ** → промежуточная фиксация
5. **Остатки после сдачи** → финальная фиксация

#### 5.3.3. Автоматическое списание

**Формула:** Автосписание = Закуплено − Остаток фактический

### 5.4. Отчёты

#### 5.4.1. Типы отчётов

1. **По месяцам** - группировка по периодам
2. **По объектам** - сводка по каждому объекту
3. **По ответственным** - статистика по пользователям
4. **По материалам** - анализ закупок материалов

#### 5.4.2. Форматы отчётов

- **Таблицы** с детализацией
- **Диаграммы** для визуализации
- **Выгрузка в Excel** с фильтрами
- **Выгрузка в PDF** с фильтрами

#### 5.4.3. Фильтры отчётов

- Период (дата от/до)
- Объекты (множественный выбор)
- Ответственные
- Материалы
- Статус (активные/архивные)
