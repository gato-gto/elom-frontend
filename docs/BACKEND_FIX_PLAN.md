# План доработки Backend API

## 🎯 Цель
Исправить несоответствия между frontend и backend API для корректной работы приложения.

## 📋 План выполнения

### Этап 1: Критические исправления (Высокий приоритет)

#### ✅ Задача 1: Исправить PurchaseSerializer
**Файл:** `purchases/serializers.py`
**Проблема:** Отсутствуют поля `object_name` и `responsible_name`
**Решение:** Добавить read-only поля в сериализатор

#### ✅ Задача 2: Обновить PurchaseFilter  
**Файл:** `purchases/filters.py`
**Проблема:** Отсутствует фильтр по материалу и алиасы дат
**Решение:** Добавить фильтр `material` и алиасы `date_after`/`date_before`

#### ✅ Задача 3: Исправить ImportPrepareView
**Файл:** `purchases/views.py`
**Проблема:** Несоответствие формата ответа frontend типам
**Решение:** Привести к единому формату

### Этап 2: Дополнительные исправления (Средний приоритет)

#### ✅ Задача 4: Обновить StockSnapshotSerializer
**Файл:** `stock/serializers.py`
**Проблема:** Отсутствуют поля `purchased_qty`, `write_off_qty`
**Решение:** Добавить computed поля или убрать из frontend типов

#### ✅ Задача 5: Обновить ArchivePeriodSerializer
**Файл:** `stock/serializers.py`
**Проблема:** Отсутствует поле `is_closed`
**Решение:** Добавить computed поле

### Этап 3: Тестирование

#### ✅ Задача 6: Протестировать изменения
**Действия:**

- Проверить импорт Excel
- Протестировать работу с остатками

## 🚀 Начинаем выполнение

Готовы приступить к выполнению плана. Начнем с критических исправлений.
