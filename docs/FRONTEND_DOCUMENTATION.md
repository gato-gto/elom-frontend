# 📚 Документация Frontend (ELOM)

## 🏗️ Архитектура приложения

### Технологический стек
- **Vue 3** + Composition API

## 🔧 API интеграция

### Stores (Pinia)
Каждая сущность имеет свой store:
- `useAuthStore` - аутентификация
- `useMaterialsStore` - материалы
- `useObjectsStore` - объекты
- `useEmployeesStore` - сотрудники
- `useUnitsStore` - единицы измерения
- `usePurchasesStore` - закупки

### Автоматические фильтры
Все списки поддерживают автоматический поиск:
```typescript
// Watcher для автоматического поиска
watch(
  () => store.filters,
  () => {
    store.pagination.page = 1
    debouncedSearch()
  },
  { deep: true }
)
```

### Поддерживаемые поля фильтрации
- **Materials:** `search`, `name`, `sku`, `category`, `default_unit`, `ordering`
- **Objects:** `search`, `name`, `is_active`, `ordering`
- **Employees:** `search`, `role`, `is_active`, `object`, `ordering`
- **Units:** `search`, `code`, `name`, `ordering`
- **Purchases:** `date_from`, `date_to`, `object`, `material`, `responsible`, `search`, `is_archived`, `ordering`
