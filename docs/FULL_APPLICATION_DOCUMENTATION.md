## 📋 **ОБЩАЯ ИНФОРМАЦИЯ**

### 🎯 **Назначение системы**
ELOM (Electronic Logistics and Operations Management) - комплексная система управления закупками и остатками материалов для строительных объектов. Система автоматизирует весь цикл работы с материалами: от закупки до списания, включая контроль остатков и формирование отчетности.

### 🏗️ **Архитектура**
- **Backend**: Django 4.2 + Django REST Framework
- **Frontend**: Vue.js 3 + TypeScript + Tailwind CSS
- **База данных**: SQLite (dev) / PostgreSQL (prod)
- **Интеграции**: Telegram Bot API для уведомлений

## 👥 **СИСТЕМА РОЛЕЙ И ДОСТУПА**

### **Роли пользователей**

#### 🔴 **Admin (Администратор)**
- **Полные права**: Управление всеми данными и настройками
- **Доступ**: Все функции системы без ограничений
- **Особенности**: Может менять статусы любых закупок

#### 🔵 **Director (Директор)**  
- **Права**: Просмотр всех данных, аналитика
- **Доступ**: Все объекты и отчеты
- **Ограничения**: Нет прав на создание/редактирование

#### 🟢 **Coordinator (Координатор)**
- **Права**: Просмотр всех данных
- **Доступ**: Все объекты (только чтение)
- **Функции**: Координация работ, контроль процессов

#### 🟡 **Brigadier (Бригадир)**
- **Права**: Полное управление назначенными объектами
- **Функции**: Создание/редактирование закупок, изменение статусов
- **Ответственность**: Может быть ответственным за объекты и закупки
- **Обязательно**: Указание номера телефона

#### 🟠 **Buyer (Покупатель)**
- **Права**: Создание и редактирование закупок по назначенным объектам
- **Ограничения**: Не может быть ответственным за объекты
- **Обязательно**: Указание номера телефона

#### 🟣 **Site Manager (Менеджер объекта)**
- **Права**: Управление остатками по назначенным объектам
- **Функции**: Создание списаний, просмотр закупок
- **Обязательно**: Указание номера телефона

## 🏢 **МОДУЛЬ: ОБЪЕКТЫ**

### **Описание**
Управление строительными объектами - центральная сущность системы, к которой привязаны все закупки и остатки материалов.

### **Основные поля**
- **Название объекта** *(обязательно)*: Уникальное название проекта
- **Ответственный** *(обязательно)*: Бригадир, отвечающий за объект
- **Ключевое лицо** *(обязательно)*: Имя прораба на объекте
- **Контакты ключевого лица** *(обязательно)*: Телефон, email прораба
- **Дата начала работ** *(обязательно)*: Планируемая дата старта
- **Адрес**: Местоположение объекта
- **Координаты**: Широта и долгота для навигации
- **Ссылка на карту**: URL для быстрого доступа к локации
- **Дата окончания**: Планируемая дата завершения

### **Функции**
- ✅ **CRUD операции**: Создание, просмотр, редактирование, удаление
- ✅ **Валидация роли**: Ответственным может быть только бригадир
- ✅ **Привязка пользователей**: Назначение доступных объектов
- ✅ **Фильтрация**: По активности, ответственному, датам

### **API Endpoints**
```
GET    /api/v1/common/objects/          # Список объектов
POST   /api/v1/common/objects/          # Создание объекта
GET    /api/v1/common/objects/{id}/     # Детали объекта
PUT    /api/v1/common/objects/{id}/     # Обновление объекта
DELETE /api/v1/common/objects/{id}/     # Удаление объекта
```

## 💰 **МОДУЛЬ: ЗАКУПКИ**

### **Описание**
Основной модуль для учета закупок материалов. Включает управление статусами, фотографиями и автоматические уведомления.

### **Статусы закупок**
- 🟢 **new (Новая)**: Только созданная закупка
- 🔵 **completed (Выполнено)**: Закупка завершена *(ранее "Принято")*
- 🔴 **cancelled (Отмена)**: Закупка отменена

### **Основные поля**
- **Дата закупки** *(обязательно)*
- **Объект** *(обязательно)*: Привязка к строительному объекту
- **Поставщик** *(обязательно)*: Выбор из справочника поставщиков
- **Ответственный** *(обязательно)*: Только пользователи с ролью "Бригадир"
- **Номер закупки**: Автогенерируемый уникальный номер (P0001, P0002...)
- **Номер накладной/чека**: Документооборот
- **Статус** *(обязательно)*: Текущее состояние закупки
- **Комментарий**: Дополнительная информация
- **Общая сумма**: Автоматический расчет по позициям
- **Валюта**: По умолчанию UZS

### **Позиции закупок**
- **Материал**: Выбор из каталога
- **Единица измерения**: Привязка к материалу
- **Количество**: Decimal с точностью до 6 знаков
- **Цена**: За единицу (опционально)
- **Сумма**: Автоматический расчет

### **Фотографии закупок**
#### **Типы фото**:
- 📸 **instructions (Инструкции)**: При создании закупки (необязательно)
- 📋 **report (Отчет)**: При смене статуса на "Выполнено" (обязательно)

#### **Валидация фото**:
- ✅ **Обязательность**: Нельзя установить статус "Выполнено" без фото отчета
- ✅ **Размер**: Максимум 10 MB на файл
- ✅ **Форматы**: JPEG, PNG, WebP

### **Права доступа**
- **Изменение статуса**: Только ответственный (бригадир) или администратор
- **Создание**: Бригадиры, покупатели (по своим объектам)
- **Просмотр**: Согласно назначенным объектам

### **API Endpoints**
```
GET    /api/v1/purchases/                      # Список закупок
POST   /api/v1/purchases/                      # Создание закупки
GET    /api/v1/purchases/{id}/                 # Детали закупки
PUT    /api/v1/purchases/{id}/                 # Обновление закупки
DELETE /api/v1/purchases/{id}/                 # Удаление закупки

# Управление фото
POST   /api/v1/purchases/{id}/photos/upload/   # Загрузка фото
GET    /api/v1/purchases/{id}/photos/          # Список фото
PUT    /api/v1/purchases/{id}/photos/{photo_id}/ # Обновление фото
DELETE /api/v1/purchases/{id}/photos/{photo_id}/ # Удаление фото

# Массовые операции
POST   /api/v1/purchases/bulk_archive/         # Массовое архивирование
POST   /api/v1/purchases/bulk_delete/          # Массовое удаление
POST   /api/v1/purchases/{id}/duplicate/       # Дублирование закупки

# Статистика и аналитика
GET    /api/v1/purchases/statistics/           # Общая статистика
GET    /api/v1/purchases/supplier-analysis/    # Анализ по поставщикам

# Импорт из Excel
POST   /api/v1/purchases/import/prepare/       # Подготовка импорта
POST   /api/v1/purchases/import/dry_run/       # Пробный импорт
POST   /api/v1/purchases/import/commit/        # Финальный импорт
```

## 📦 **МОДУЛЬ: ОСТАТКИ И ДВИЖЕНИЯ**

### **Описание**
Система учета остатков материалов с автоматическим формированием движений и контролем списаний.

### **Снимки остатков (StockSnapshot)**
- **Журнал движений**: Все приходы и расходы материалов
- **Автоматическое создание**: При закупках и списаниях
- **Подписанное количество**: Положительное для прихода, отрицательное для расхода
- **Этапы работ**: acceptance, request, delivery_fixed, post_rough, handover
- **Связь с источником**: Ссылка на Purchase или WriteOff

### **Списания (WriteOff)**
- **Контроль остатков**: Нельзя списать больше чем есть
- **Этапы работ**: Привязка к стадиям строительства
- **Валидация**: Автоматическая проверка доступного остатка
- **Причины**: Строительство, порча, хищение, недостача

### **API Endpoints**
```
GET    /api/v1/stock/snapshots/               # Журнал движений
POST   /api/v1/stock/snapshots/               # Создание движения
GET    /api/v1/stock/snapshots/{id}/          # Детали движения

GET    /api/v1/stock/writeoffs/               # Список списаний
POST   /api/v1/stock/writeoffs/               # Создание списания
GET    /api/v1/stock/writeoffs/{id}/          # Детали списания
PUT    /api/v1/stock/writeoffs/{id}/          # Обновление списания
DELETE /api/v1/stock/writeoffs/{id}/          # Удаление списания

GET    /api/v1/stock/balance/                 # Текущие остатки
```

## 📱 **МОДУЛЬ: TELEGRAM УВЕДОМЛЕНИЯ**

### **Описание**
Автоматическая система уведомлений в Telegram при изменениях в закупках.

### **Настройки**
- **TelegramSettings**: Конфигурация бота (token, chat_id)
- **Активация через админку**: Настройка в Django Admin
- **Безопасность**: Токен бота хранится в зашифрованном виде

### **События для уведомлений**
1. **Создание закупки** - отправляется при создании новой закупки
2. **Смена статуса** - при изменении статуса закупки
3. **Добавление фото** - при загрузке новых фотографий

### **Содержимое сообщений**
```
🆕 Закупка P0001

📋 Статус: Новая
👤 Ответственный: Иван Иванов
🏢 Объект: ЖК Солнечный
🏪 Поставщик: ООО Стройматериалы
📅 Дата: 24.09.2025
📍 Локация: [ссылка на карту]
💬 Комментарий: Закупка кабеля
📄 № счета: A-12345
💰 Сумма: 150,000 UZS
```

### **Фото в сообщениях**
- ✅ **При смене статуса на "Выполнено"**: Автоматически прикрепляются фото отчета
- ✅ **При добавлении фото**: Отдельное уведомление с загруженным фото
- ✅ **Ограничения**: Максимум 5 фото за раз

### **Модели**
```python
class TelegramSettings:
    chat_id: str           # ID группы для уведомлений
    bot_token: str         # Токен Telegram бота
    is_active: bool        # Включены ли уведомления

class TelegramNotification:
    purchase: Purchase     # Связанная закупка
    message_type: str      # Тип события
    message_text: str      # Текст сообщения
    is_sent: bool         # Статус отправки
    sent_at: datetime     # Время отправки
    error_message: str    # Ошибка (если есть)
```
