# ELOM Frontend - План разработки

*Создано: 2025-01-27*
*Статус: В разработке*

## 📊 Текущее состояние проекта

### ✅ Что уже реализовано:
- **Архитектура**: Vue 3 + TypeScript + Vite + Tailwind CSS v4 + DaisyUI
- **State Management**: Pinia с auth и ui stores
- **API**: Axios с интерцепторами, refresh token логика, полная типизация
- **Компоненты**: Table, FormField, Pagination, Modal, ToastCenter и др.
- **Auth**: JWT с автоматическим обновлением токенов, роли пользователей
- **Страницы**: Базовая структура всех страниц (Materials, Purchases, Reports и др.)

### ⚠️ Проблемы и недостатки:
- Отсутствует роутинг (`src/router/index.ts`)
- Нет AppLayout с навигацией
- Неполная реализация stores для данных
- Страницы используют прямые API вызовы вместо stores
- Неполная интеграция универсальных компонентов

### Excel-parity достигнут когда:

1. [ ] Авторизация и проверка ролей
2. [ ] Создание закупки с фото → сумма/валюта корректны
3. [ ] Списание на складе → остатки обновлены
4. [ ] Архив периода → изменения заблокированы
5. [ ] Формирование отчета → экспорт XLSX соответствует шаблону

## 📝 Заметки

### Технические решения:
- Используем DaisyUI для всех UI компонентов
- Stores содержат только данные, переводы в компонентах
- URL как источник правды для фильтров/пагинации
- Строгая типизация без `any`

### Известные проблемы:
- Некоторые страницы используют прямые API вызовы
- Отсутствует единообразие в обработке ошибок
- Нет loading states в некоторых местах
