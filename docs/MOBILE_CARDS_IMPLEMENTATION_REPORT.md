## 📊 **ДЕТАЛЬНЫЙ ОБЗОР КАРТОЧЕК**

### **1. PurchaseCard - Карточка закупки**
**Отображаемые поля:**
- 🆔 Номер закупки и дата
- 🏢 Объект и поставщик
- 👤 Ответственный
- 💰 Общая сумма (выделена)
- 📊 Количество позиций и фото (бейджи)
- 💬 Комментарий (если есть)
- 📅 Даты создания/обновления

**Статусы:**
- 🟢 **Новая** - badge-info (синий)
- 🔵 **Выполнено** - badge-success (зеленый)
- 🔴 **Отмена** - badge-error (красный)

**Действия:**
- ✏️ Редактировать (btn-outline)
- 🗑️ Удалить (btn-error)

### **2. MaterialCard - Карточка материала**
**Отображаемые поля:**
- 🖼️ Фото материала (avatar) или иконка 📦
- 📝 Название и SKU
- 🏷️ Категория (badge-secondary)
- 📏 Единица измерения
- 📈 Количество закупок
- 📊 Текущий остаток (выделен зеленым)
- 💰 Средняя цена
- 🏭 Производитель
- 📄 Описание (сокращенное)
- 📊 Статистика (stats компонент)

**Особенности:**
- Аватар с фото или плейсхолдер
- Цветовая индикация остатков
- Компактная статистика

### **3. ObjectCard - Карточка объекта**
**Отображаемые поля:**
- 🏗️ Название объекта
- 📍 Адрес
- 📅 Даты начала и окончания
- 👤 Ответственный (цветом primary)
- 👷 Прораб и его контакты
- 📈 Прогресс проекта (progress bar)
- ⏰ Оставшиеся дни
- 🗺️ Кнопка "Открыть на карте"

**Особенности:**
- Прогресс-бар для визуализации хода работ
- Умный расчет оставшихся дней
- Интеграция с картами

### **4. EmployeeCard - Карточка сотрудника**
**Отображаемые поля:**
- 👤 Полное имя и логин
- 📧 Email и телефон
- 🎭 Роль (цветной бейдж)
- ✅ Статус активности
- 🏢 Назначенные объекты (чипы)
- 📊 Статистика закупок
- 🕐 Последний вход

**Особенности:**
- Цветовая кодировка ролей
- Компактный список объектов
- Статистика активности

### **5. StockCard - Карточка движения**
**Отображаемые поля:**
- 📦 Материал и объект
- 📅 Дата движения
- ➕/➖ Количество с знаком (цветовая индикация)
- 🔄 Тип движения (приход/расход)
- 🏗️ Этап работ
- 👤 Ответственный
- 🔗 Источник (закупка/списание)
- 🔄 Умная конвертация (если есть)

**Особенности:**
- Цветовая индикация: зеленый для прихода, красный для расхода
- Центральное отображение количества
- Бейджи для этапов

### **6. WriteOffCard - Карточка списания**
**Отображаемые поля:**
- 📦 Материал и объект
- 📅 Дата списания
- ➖ Количество списания (красным)
- 📊 Остаток до и после списания
- 🏗️ Этап работ
- 👤 Ответственный
- ⚠️ Предупреждения валидации
- 💬 Комментарий

**Особенности:**
- Красная индикация расхода
- Показ остатка до/после
- Предупреждения о низких остатках

### **7. UnitCard - Карточка единицы**
**Отображаемые поля:**
- 📏 Код единицы (крупно)
- 📝 Полное название
- 📊 Статистика использований
- 🔄 Конверсии с другими единицами
- 📦 Примеры материалов

**Особенности:**
- Крупное отображение кода
- Компактная статистика
- Список конверсий

## 🚀 **ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ**

### **Адаптивность:**
```css
/* Автоматическое скрытие/показ */
@media (max-width: 767px) {
  .desktop-only { display: none; }
}

@media (min-width: 768px) {
  .mobile-only { display: none; }
}
```

### **Плавные анимации:**
```css
.mobile-cards-container .card {
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.card:hover {
  transform: translateY(-1px) scale(1.01);
  box-shadow: 0 10px 25px rgba(0,0,0,0.1);
}
```

### **Умная загрузка:**
- **Desktop**: TableSkeleton с каркасом таблицы
- **Mobile**: Анимированные заглушки карточек
- **Overlay**: Полупрозрачное покрытие при обновлении
