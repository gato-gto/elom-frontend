## 🧭 ЗОНЫ ИНТЕРФЕЙСА

### 1. ТОПБАР (верхняя панель)

```
☰ Меню  |  ELOM  |  🔔(3)  |  🌙  |  Иванов И.П. ▼
```

| Элемент | Что делает |
|---------|------------|
| **☰ Меню** | Открыть/закрыть боковое меню (на мобильных) |
| **ELOM** | Логотип, клик → на главную |
| **🔔 (3)** | Уведомления, цифра = непрочитанные |
| **🌙** | Переключение темы (светлая/тёмная) |
| **Иванов И.П. ▼** | Профиль, настройки, выход |

## 🎨 ЭЛЕМЕНТЫ ИНТЕРФЕЙСА

### Кнопки:

```
➕ Добавить      — создать новое (синяя)
✏️ Редактировать — изменить (серая)
🗑️ Удалить       — удалить (красная)
👁️ Просмотр      — открыть детали (синяя)
📥 Экспорт       — скачать файл (зелёная)
🔄 Обновить      — перезагрузить (серая)
```

### Бейджи статусов:

```
🔵 Новая      — синий (можно редактировать)
🟢 Выполнено  — зелёный (завершено)
🔴 Отменена   — красный (отменено)
🟡 В работе   — жёлтый (процесс)
⚫ Неактивен   — серый (отключено)
```

### Индикаторы:

```
✅ Да / Активен     — зелёная галочка
❌ Нет / Неактивен  — красный крестик
⚠️ Предупреждение   — жёлтый треугольник
ℹ️ Информация       — синий кружок с i
```

```
┌─────────────────────────────────────────────────────┐
│ ✖                                                    │← Закрыть (крестик)
│         Создание закупки                             │← Заголовок
├─────────────────────────────────────────────────────┤
│                                                      │
│  Основная информация                                │← Секция
│  ┌────────────────────┬────────────────────┐        │

│  └────────────────────┴────────────────────┘        │
│  ┌──────────────────────────────────────────┐       │
│  │ Поставщик: [ООО СтройБаза ▼]             │       │← Поле (полная ширина)
│  └──────────────────────────────────────────┘       │
│                                                      │
│  Материалы                                          │← Секция
│  ┌──────────────────────────────────────────┐       │
│  │ Материал │ Количество │ Цена │ Сумма    │       │← Позиции
│  │ Цемент   │ 2000       │ 2500 │ 5,000,000│ 🗑️   │
│  │          │            │      │          │ ➕    │← Добавить ещё
│  └──────────────────────────────────────────┘       │
```

### Что означают элементы:

- **[Поле ▼]** — выпадающий список (клик → варианты)

- **📅 Дата** — календарь (клик → выбор даты)
- **🗑️** — удалить строку
- **➕** — добавить строку
- **[Сохранить]** — синяя кнопка (главное действие)
- **[Отмена]** — серая кнопка (закрыть без сохранения)

## 📊 ТИПЫ СПИСКОВ

### Тип 1: Справочники (редко меняются)

```
Материалы, Объекты, Сотрудники, Поставщики, Единицы, Категории материалов
```

**Характеристики**:
- Создаёте один раз
- Используете многократно
- Редко удаляете
- Часто фильтруете и ищете

**Действия**:
- ➕ Добавить → создать новое
- ✏️ Редактировать → изменить
- 🗑️ Удалить → удалить (если нет связей)

---

### Тип 2: Операции (создаёте постоянно)

```
Закупки, Списания
```

**Характеристики**:
- Создаёте ежедневно
- Редко редактируете (только если ошибка)
- Почти не удаляете
- Часто фильтруете по дате, объекту

**Действия**:
- ➕ Добавить → новая операция
- 👁️ Просмотр → детали
- ✏️ Редактировать → исправить (если не архив)
- 🗑️ Удалить → удалить (если не архив)

---

### Тип 3: Просмотр (только читаете)

```
Остатки → Движения, Остатки → По объектам
```

**Характеристики**:
- Не создаёте напрямую (формируются автоматически)
- Только просмотр
- Фильтры и экспорт

**Действия**:
- 🔍 Фильтровать → найти нужное
- 📊 Сортировать → упорядочить
- 📥 Экспорт → скачать

---

### Тип 4: Отчёты (аналитика)

```
Отчёты → По периодам, По объектам, По материалам, По ответственным
```

**Характеристики**:
- Настраиваете фильтры
- Генерируете по запросу
- Экспортируете в Excel

**Действия**:
- ⚙️ Настроить → выбрать параметры
- 📊 Показать → сформировать отчёт
- 📥 Экспорт → скачать файл

## 🔀 СВЯЗИ МЕЖДУ РАЗДЕЛАМИ

### Материал → Закупка → Списание → Остаток

```
1. Материалы
   └─→ Создали "Цемент М400" с единицей "кг"
        │
        ↓
2. Закупки
   └─→ Закупили 2000 кг для "Дома №1"
        │
        ↓ Автоматически:
        ├─→ Журнал движений: +2000 кг
        └─→ Остаток на объекте: 2000 кг
             │
             ↓
3. Списания
   └─→ Списали 500 кг с "Дома №1"
        │
        ↓ Автоматически:
        ├─→ Журнал движений: −500 кг
        └─→ Остаток на объекте: 1500 кг
             │
             ↓
4. Остатки
   └─→ Показывает: 1500 кг на "Доме №1"
```

---

### Объект → Закупки → Списания → Остатки

```
Создали объект "Дом №1"
      │
      ├─→ Все закупки на этот объект
      │    └─→ Фильтр: Объект = "Дом №1"
      │
      ├─→ Все списания с этого объекта
      │    └─→ Автофильтрация материалов
      │
      └─→ Остатки по этому объекту
           └─→ Остатки → По объектам → "Дом №1"
```

---

### Поставщик → Закупки → Анализ цен

```
Создали поставщика "ООО СтройБаза"
      │
      └─→ Используется в закупках
           │
           └─→ Статистика:
               ├─ Сколько закупок
               ├─ На какую сумму
               └─ Средний чек
                  │
                  └─→ Отчёты → По материалам
                      └─→ Сравнение цен
```

## 🎯 КАРТА ДЕЙСТВИЙ ПО РОЛЯМ

### 🟢 BRIGADIER (Бригадир)

#### Ежедневные задачи:

```
Утро:
  Остатки → По объектам
  └─→ Проверка наличия материалов

День:
  Закупки → ➕ Добавить
  └─→ Регистрация поступлений

Вечер:
  Списания → ➕ Добавить
  └─→ Фиксация расхода
```

#### Доступные разделы:
- ✅ Материалы (просмотр, создание)
- ✅ Объекты (просмотр своих)
- ✅ Закупки (создание, редактирование своих)
- ✅ Списания (создание, редактирование)
- ✅ Остатки (просмотр своих объектов)
- ✅ Поставщики (просмотр, создание)
- ❌ Сотрудники (нет доступа)
- ❌ Единицы (нет доступа)
- ✅ Категории материалов (просмотр, создание)
- ✅ Отчёты (просмотр по своим объектам)
- ❌ Архив (нет доступа)

---

### 🟣 DIRECTOR (Директор)

#### Еженедельные задачи:

```
Понедельник:
  Отчёты → По объектам
  └─→ Анализ затрат по объектам
  
Среда:
  Отчёты → По ответственным
  └─→ Оценка работы бригадиров

Пятница:
  Закупки → фильтр: статус "Новая"
  └─→ Проверка фотоотчётов
```

#### Ежемесячные задачи:

```
Конец месяца:
  Отчёты → По материалам
  └─→ Экспорт → Excel
  
  Архив → Закрыть период
  └─→ Для каждого объекта
```

#### Доступные разделы:
- ✅ ВСЕ РАЗДЕЛЫ (полный доступ)

---

### 🟡🔴 BUYER и SITE MANAGER (УДАЛЕНЫ)

> **Важно (ноябрь 2025):** Роли **Buyer** (Закупщик) и **Site Manager** (Менеджер объекта) удалены из системы.
> 
> Все их функции теперь выполняет роль **Brigadier** (Бригадир):
> - ✅ Закупки (создание, редактирование)
> - ✅ Списания (создание, редактирование)
> - ✅ Остатки (просмотр своих объектов)
> - ✅ Отчёты (просмотр по своим объектам)
>
> При миграции все существующие пользователи с ролями `buyer` и `site_manager` автоматически конвертированы в `brigadier`.
- ❌ Архив (нет доступа)

```

       ↓
Шаг 2: Заполнить основные данные
       ↓
Шаг 3: Добавить материалы (➕ позиции)
       ↓
Шаг 4: Загрузить фото
       ↓

```

### Процесс 2: Фиксация расхода материалов

```
Шаг 1: Списания → ➕ Добавить
       ↓
Шаг 2: Выбрать объект
       ↓ автоматически
       ├─ Материалы отфильтровались
       └─ Ответственный подставился
       ↓
Шаг 3: Выбрать материал
       ↓ автоматически
       ├─ Единица подставилась
       └─ Остаток показался
       ↓
Шаг 4: Ввести количество
       ↓
Шаг 5: Сохранить
       ↓
Результат: ✅ Расход учтён (остатки ↓)
```

---

### Процесс 3: Проверка остатков

```
Способ 1 (по объекту):
  Остатки → По объектам → выбрать объект
  └─→ Видите: все материалы на объекте

Способ 2 (по материалу):
  Остатки → Движения → фильтр: материал
  └─→ Видите: все объекты где есть этот материал

Способ 3 (детальная история):
  Остатки → Движения → фильтр: объект + материал
  └─→ Видите: все приходы и расходы
```

```
       ↓

       ├─ Период (дата с… по…)

       └─ Ответственный (кто)
       ↓
Шаг 3: Нажать "Показать"
       ↓
Шаг 4: Просмотр таблицы
       ↓
Шаг 5: Экспорт → Excel
       ↓
Результат: ✅ Файл скачан
```
