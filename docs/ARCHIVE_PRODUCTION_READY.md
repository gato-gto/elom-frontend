## 🔧 **Новые возможности**

### **Management команды:**
```bash
# Архивирование периода
python manage.py archive_period --object-id 1 --month 2024-01 --user-id 1

# Просмотр архивов
python manage.py list_archives --year 2024 --format json

# Dry-run (проверка без выполнения)
python manage.py archive_period --object-id 1 --month 2024-01 --user-id 1 --dry-run
```

### **Celery задачи:**
```python
# Автоматическое архивирование
auto_archive_old_periods_task.delay()

# Проверка целостности
check_archive_integrity_task.delay()

# Очистка старых архивов
cleanup_old_archives_task.delay()
```

## 🚀 **Production настройка**

### **1. Backend настройки:**
```python
# settings.py
CELERY_BEAT_SCHEDULE = {
    'auto-archive-old-periods': {
        'task': 'stock.tasks.auto_archive_old_periods_task',
        'schedule': crontab(day_of_week=1, hour=2, minute=0),  # Каждый понедельник в 2:00
    },
    'check-archive-integrity': {
        'task': 'stock.tasks.check_archive_integrity_task',
        'schedule': crontab(hour=3, minute=0),  # Каждый день в 3:00
    },
}

# Настройка хранения архивов
ARCHIVE_RETENTION_YEARS = 5  # Хранить архивы 5 лет
```
