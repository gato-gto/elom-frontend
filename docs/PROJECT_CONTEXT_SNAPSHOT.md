## 🏗️ **АРХИТЕКТУРА ПРОЕКТА**

### **Технологический стек:**
- **Frontend:** Vue 3 + TypeScript + Vite
- **UI Framework:** Tailwind CSS + DaisyUI
- **State Management:** Pinia
- **Routing:** Vue Router
- **HTTP Client:** Axios
- **Build Tool:** Vite

### **Структура проекта:**
```
src/
├── api/           # API клиент, типы, endpoints
├── components/    # Переиспользуемые компоненты
├── layouts/       # Макеты страниц
├── pages/         # Страницы приложения
├── stores/        # Pinia stores
├── utils/         # Утилиты и хелперы
└── router/        # Конфигурация маршрутов
```

## 🆕 **НОВЫЕ РЕАЛИЗОВАННЫЕ ФУНКЦИИ**

### 1. **Система уведомлений** ✅
**Файлы:**
- `src/stores/notifications.ts` - store для уведомлений
- `src/components/Notifications.vue` - компонент уведомлений
- `src/components/NotificationItem.vue` - отдельное уведомление
- `src/api/types.ts` - интерфейс Notification

**Функциональность:**

- Уведомления об ошибках
- Счетчик непрочитанных
- Автоматическое удаление старых уведомлений
- Интеграция в основной layout

### 2. **Система конвертации единиц** ✅
**Файлы:**
- `src/stores/unitConversions.ts` - store для конвертаций
- `src/utils/unitConverter.ts` - утилиты конвертации
- `src/pages/Admin/UnitConversions.vue` - админка конвертаций
- `src/pages/Admin/UnitConversionForm.vue` - форма конвертации
- `src/api/types.ts` - интерфейсы UnitConversion
- `src/api/endpoints.ts` - endpoints для конвертаций

**Функциональность:**
- CRUD операции для конвертаций
- Предустановленные конвертации (мешок ↔ кг, м ↔ см и др.)
