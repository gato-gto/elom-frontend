**Статус**: ✅ Выполнено

### 3. Backend - Автоматические уведомления о закупках ✅
**Задача**: Настроить автоматическую отправку уведомлений при событиях с закупками

**Реализовано**:
- ✅ Уведомление при создании закупки (`created`)
  - Отправляется при создании `Purchase`
  - Включает фотоинструкции (если есть)
  - Содержит: номер, дату, объект, поставщика, ответственного, сумму, комментарий, локацию

- ✅ Уведомление при изменении статуса (`status_changed`)
  - Отправляется при изменении статуса закупки
  - При статусе "completed" прикрепляет фото отчета

- ✅ Уведомление при добавлении фото (`photo_added`)
  - Отправляется при добавлении `PurchasePhoto`
  - Включает добавленное фото

**Статус**: ✅ Выполнено (через Django сигналы)

### 3. Уведомления о создании объектов ❌
**Задача**: Отправлять уведомления при создании новых объектов

**Описано в документации** (`docs/summary/05-business-logic.md`, строки 503-516):
```python
@receiver(post_save, sender=Object)
def send_object_creation_notification(sender, instance, created, **kwargs):
    if created:
        message = f"""
🏗️ Новый объект: {instance.name}
📍 Адрес: {instance.address}
👤 Ответственный: {instance.responsible.user.get_full_name()}
📸 Фото инструкций: {instance.photos.filter(type='instructions').count()} шт.
        """
        TelegramNotificationService.send_message_with_photos(message, instance.photos.all())
```

**Требуется**:
- ❌ Сигнал на `post_save` для модели `Object`
- ❌ Форматирование сообщения о создании объекта
- ❌ Отправка фото инструкций (если есть)

**Приоритет**: Средний  
**Оценка**: 2-3 часа
